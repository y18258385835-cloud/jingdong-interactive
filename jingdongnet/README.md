# 鲸动交互官网

此目录是独立官网项目，与交互软件的编辑器、注册码服务和源代码分开。

## 本地预览

```powershell
npm install
npm run dev
```

打开 `http://localhost:3100/`。内容编辑后台为 `http://localhost:3100/admin`。

## 独立部署

运行 `npm run build`，将 `dist/` 目录发布到任意静态网站托管。主站需将 `/` 指向首页，并将 `/admin` 回退到 `index.html`。

下载和注册码管理地址可以在后台中配置。生产环境请分别设置为软件安装包下载地址、软件服务器的 `/admin/licenses` 地址。目前官网文章和设置使用浏览器 `localStorage`，即后台内容保存在管理员浏览器中，尚不能跨设备、多管理员共享；公开上线前必须接入受保护的内容 API 和共享数据库。此原型不配置或假定尚未提供的安装包、购买支付页或服务器地址。
