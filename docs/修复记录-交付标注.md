# 交付标注 / 开发交接修复记录

> 目标：选中一个图层后，直接把尺寸、间距、颜色、字体、素材和 CSS 交给开发；同时支持导出可打印的标注页。

## 怎么用

1. 顶部工具栏点「标注」。
2. 在画布或图层面板选中一个图层。
3. 右侧「交付标注」面板会显示：
   - X / Y / 宽 / 高（按画布像素换算）；
   - 到画布四边的距离；
   - 到最近的上/下/左/右图层的间距；
   - 背景、描边、圆角、阴影、混合模式、背景模糊；
   - 字体、字号、字重、行高、字间距、颜色、对齐；
   - 素材 ID / 原始宽高比；
   - 组件母版、变体、覆盖字段；
   - 交互、时间轴、图层 ID、蒙版状态；
   - 可直接复制的 CSS。
4. 画布上会叠加粉色标注：
   - 图层外框；
   - 宽度尺寸线；
   - 高度尺寸线；
   - X / Y 起始位置。
5. 点「导出场景标注」会下载一个独立 HTML：
   - 顶部是带真实画布截图的标注图；
   - 每个图层一个编号框；
   - 下方是每个图层的完整标注卡片和 CSS；
   - 可直接发给开发，或浏览器打印成 PDF。

## 保护规则

- 标注层是 `pointer-events-none`，不会挡住选中、拖拽、缩放和旋转。
- 标注层使用 `data-export-hide="true"`，导出截图和播放器不会带上粉色线。
- 没有改现有选框的测量/手势逻辑，只读取它已经算好的屏幕坐标。
- 标注页对图层名、文字内容、项目名全部做 HTML 转义，避免把用户内容当脚本执行。
- 截图失败时仍会导出坐标和样式清单，不会因为 3D/视频截不到图而整个失败。
- 多选时一次只看一个图层；面板会提示先单独选中。

## 当前限制

- 一次只标注一个图层；多选只提示，不批量列标注。
- 导出的是当前场景，不跨场景合并。
- 旋转图层的粉色框按外接矩形显示；宽高和 X/Y 仍是图层自身数值，面板会提示。
- 3D 模型、全景、视频等图层可能截不到真实画面，此时标注页自动退回“坐标 + 样式”模式。
- 间距只计算到画布四边和最近的同侧图层，不做任意两个图层之间的手动测距。
- 标注页是静态快照，不会随工程更新自动同步。
