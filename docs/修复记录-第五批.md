# 修复记录 · 第五批（首屏性能 + 两个遗留点）

## 1. 城市地图数据改为按需加载

`officialCityMapData.ts` 里是 38 个城市的 SVG 路径，约 **1.81 MB**，之前被 `InspectorPanel`、`GalaxyComponents`、`officialComponentModel`、`OfficialComponentsModal` 静态引用，直接进了首屏主包。

改造方式：

- 新增 `tools/build-city-map-index.mjs`：从几何数据里提取「城市 ID → 城市名」的轻量索引，生成 `cityMapIndex.ts`（约 2 KB）。
- 新增 `cityMapRegistry.ts`：几何数据只在 `OfficialCityMapGraphic` 真正挂载时通过 `import()` 加载，并提供 `useCityMaps()` 订阅式 hook。
- 五个消费方全部改为使用索引 / registry：
  - `officialComponentModel`：地图默认值改用名称索引
  - `GalaxyComponents`：判空改用 `isCityMapId()`
  - `InspectorPanel`：地图下拉改用 `CITY_MAP_NAMES`
  - `OfficialComponentsModal`：地图组件目录改用名称索引
  - `OfficialCityMapGraphic`：改为 `useCityMaps()`
- `src/main.tsx`：导出播放器模式启动时预热地图数据，避免成品第一帧空白（播放器构建是 `inlineDynamicImports`，动态 chunk 会被内联进单文件）。

### 体积变化

| | 改造前 | 改造后 |
|---|---|---|
| 首屏主 chunk（raw） | 4.68 MB | **2.87 MB** |
| 首屏主 chunk（gzip） | 1.31 MB | **0.76 MB** |
| 地图 chunk | 无（在主包里） | 1.81 MB（按需加载） |

首屏 JS 减少约 **39%**（gzip 减少 42%）。

付费用户导出后仍是原来的 800 ms 自动关闭，不打扰。
