# 命名版本 + 评论评审修复记录

> 目标：改到关键节点能一键存档、随时恢复；客户/同事的意见可以直接钉在画布上，改完点“解决”。

## 命名版本

### 原来

只有撤销/重做和时间线历史。想回到“昨天给客户看的第 3 版”，只能靠回忆和反复撤销。

### 现在

工具栏右侧新增「版本」入口：

- 输入名称，保存当前工程快照；
- 每个版本记录时间、场景数、图层数；
- 点「恢复」两次确认后回到该版本；
- 恢复前会自动保存当前状态为「自动备份 · 恢复前」，避免误点丢内容；
- 最多保留 12 个版本，超出自动淘汰最旧的；
- 版本按工程 ID 存在 IndexedDB 偏好区，刷新/重开工程仍在；
- 版本快照包含场景、图层、组件母版、变量和评论。

### 实测

```text
保存「测试版本」
刷新页面后：版本仍存在 ✅
移动 s1_cta_text：x 31 → 34
恢复「测试版本」：x 34 → 31 ✅
```

## 评论评审

### 原来

客户意见只能截图发微信，改完再截图确认，找不到“这条评论对应画布哪里”。

### 现在

工具栏新增「评论」入口：

- 进入评论模式后，画布变成浅青色，点任意位置即可钉评论；
- 评论以编号圆点显示在画布上，已解决的显示 ✓；
- 点评论圆点可以直接看内容、标为已解决、删除；
- 右侧「评论与评审」面板集中查看：
  - 未解决 / 全部筛选；
  - 显示评论内容、作者、时间、所在场景；
  - 「定位」会切到对应场景并高亮评论；
  - 支持解决 / 重新打开 / 删除。

评论存在工程数据里，跟随工程保存；导出时会自动剥离，不会把内部评审意见发给客户。

### 实测

```text
评论模式点击画布 60% / 40% 位置
→ 输入「这里再大一点」
→ 评论圆点出现 ✅
→ 评论面板看到内容 ✅
→ 点「解决」后 resolved = true ✅
```

截图：`promo/out/galaxy/versions-comments.png`

验证脚本：`promo/probe-versions-comments.mjs`

## 当前 v1 限制

- 版本存在本机 IndexedDB，不随工程 ZIP 导出，也不跨设备同步；
- 评论只在编辑器里显示，演示/导出播放器不显示；
- 评论暂不支持回复、@人、图片附件；
- 没有团队实时协作（按之前约定 team 档暂不做）。
