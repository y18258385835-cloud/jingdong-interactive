# 修复记录 · 第二十三批（防绕过 / 持久化 / 工程化）

## 1. 免费导出额度绑定设备指纹

之前额度只按 `localStorage` 里的 `aether_device_id` 记账，清缓存即可重置。

- 客户端（`subscriptionService`）新增弱指纹：`UA + 语言 + CPU 核数 + 平台 + 屏幕尺寸/色深 + 时区`，FNV-1a 哈希后通过 `X-Aether-Fingerprint` 发送
- 服务端（`website/server.js` + `server/license-service.js`）同时按 `deviceHash` 与 `fp-*` 记账，额度取两者较大值
- 实测：同一指纹换 3 个 deviceId，第 4 次仍被拒绝

## 2. 撤回栈迁到 IndexedDB

- 持久化从 `localStorage` 改为 `aetherDB.setPreference('project-history:<id>')`
- 保留条数 8 → **20 条**
- 删除「序列化 >900KB 直接清空」的逻辑（大工程刷新后不再丢撤回）
- 旧 localStorage 记录读取一次后自动删除（平滑迁移）
- 实测：添加图层 → 刷新 → 历史面板仍显示 2/2

## 3. 控制桥按需上报

编辑器每 1.5 秒上报快照，现在先在客户端做 JSON 比对，内容没变就不发包；失败后自动清空缓存以便重试。

## 4. 导出目录自动清理

`data/exports/` 每次写入后清理：只保留最近 **50 个**、**7 天**内的文件。

## 5. 工程化：CI + 一键检查

- 新增 `.github/workflows/ci.yml`：
  - `check` job：版本一致性 → tsc → vitest → i18n 报告 → build
  - `e2e` job：安装 chromium 后跑 Playwright，失败上传报告
- 新增 `npm run check`：本地一条命令跑「版本 + 类型 + 单测 + i18n」
