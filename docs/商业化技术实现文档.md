## 1. 整体架构设计

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **素材不出本地** | 所有图片/视频/3D模型/全景图/高斯泼溅素材仅存在用户浏览器本地，绝不上传服务器 |
| **渲染不出本地** | WebGL 渲染、Canvas 绘制、视频编解码全部在用户浏览器执行，使用用户 CPU/GPU |
| **服务器仅做授权** | 服务器只负责：用户认证、订阅状态验证、前端静态资源托管、可选增值服务 |
| **工程可导出** | 工程配置可导出为 `.aether` 文件，用户可手动备份、跨设备迁移、分享给协作者 |

### 1.3 数据流概览

| 数据类型 | 存储位置 | 是否上传服务器 | 说明 |
|----------|----------|---------------|------|
| 工程配置（场景/元素/热点/时间线） | IndexedDB | 否（可选云端备份） | JSON 格式，体积小（几十KB~几MB） |
| 素材文件（图片/视频/3D/全景/高斯泼溅） | OPFS | 否 | 体积大（几MB~几百MB），必须本地 |
| 用户偏好设置 | IndexedDB / localStorage | 否 | 主题、快捷键、最近工程列表 |
| 用户账号信息 | 服务器数据库 | 是 | 邮箱、密码哈希、订阅状态 |
| 订阅状态缓存 | IndexedDB | 是（验证时同步） | 缓存7天，离线可用 |
| 导出文件 | 用户本地下载 | 否 | 图片/视频/HTML包，直接保存到用户电脑 |

## 2. 前端存储层设计

### 2.1 技术选型

| 存储方案 | 用途 | 选型理由 |
|----------|------|----------|
| **IndexedDB** | 工程配置、用户偏好、订阅缓存 | 结构化数据、支持索引、容量大（数百MB）、异步API |
| **OPFS** (Origin Private File System) | 素材文件、导出临时文件 | 浏览器私有文件系统、支持大文件（GB级）、性能接近本地文件、仅同源访问 |
| **localStorage** | 轻量配置（当前工程ID、UI状态） | 简单同步API、容量小（5MB） |

> **为什么用 OPFS 而不是 IndexedDB 存素材？**
> - IndexedDB 存大文件（视频/3D模型）性能差，读写需要序列化/反序列化
> - OPFS 是真正的文件系统，支持随机读写、流式读写，适合大文件
> - OPFS 支持 File System Access API 的同步访问（在 Web Worker 中），性能更好
> - 浏览器兼容性：Chrome 109+、Edge 109+、Safari 16.4+、Firefox 111+，2024年后主流浏览器全支持

```typescript
// 文件：src/core/db/indexedDB.ts

import { openDB, IDBPDatabase } from 'idb';

class AetherDB {
  private db: IDBPDatabase | null = null;

  async init(): Promise<void> {
    this.db = await openDB(DB_NAME, DB_VERSION, {
      upgrade(db) {
        // projects store
        if (!db.objectStoreNames.contains('projects')) {
          const store = db.createObjectStore('projects', { keyPath: 'id' });
          store.createIndex('by-updatedAt', 'updatedAt');
          store.createIndex('by-name', 'name');
        }
        // assets store
        if (!db.objectStoreNames.contains('assets')) {
          const store = db.createObjectStore('assets', { keyPath: 'id' });
          store.createIndex('by-projectId', 'projectId');
          store.createIndex('by-hash', 'hash');
        }
        // preferences store
        if (!db.objectStoreNames.contains('preferences')) {
          db.createObjectStore('preferences');
        }
        // subscription store
        if (!db.objectStoreNames.contains('subscription')) {
          db.createObjectStore('subscription');
        }
        // recentProjects store
        if (!db.objectStoreNames.contains('recentProjects')) {
          const store = db.createObjectStore('recentProjects', { keyPath: 'projectId' });
          store.createIndex('by-lastOpenedAt', 'lastOpenedAt');
        }
      },
    });
  }

  // 工程操作
  async saveProject(project: ProjectRecord): Promise<void> {
    project.updatedAt = Date.now();
    await this.db!.put('projects', project);
  }

  async getProject(id: string): Promise<ProjectRecord | undefined> {
    return this.db!.get('projects', id);
  }

  async listProjects(): Promise<ProjectRecord[]> {
    return this.db!.getAllFromIndex('projects', 'by-updatedAt');
  }

  async deleteProject(id: string): Promise<void> {
    await this.db!.delete('projects', id);
  }

  // 素材操作
  async saveAsset(asset: AssetRecord): Promise<void> {
    await this.db!.put('assets', asset);
  }

  async getAsset(id: string): Promise<AssetRecord | undefined> {
    return this.db!.get('assets', id);
  }

  async getAssetsByProject(projectId: string): Promise<AssetRecord[]> {
    return this.db!.getAllFromIndex('assets', 'by-projectId', projectId);
  }

  async getAssetByHash(hash: string): Promise<AssetRecord | undefined> {
    return this.db!.getFromIndex('assets', 'by-hash', hash);
  }

  async deleteAsset(id: string): Promise<void> {
    await this.db!.delete('assets', id);
  }

  // 订阅缓存操作
  async saveSubscription(sub: SubscriptionCache): Promise<void> {
    await this.db!.put('subscription', sub, 'current');
  }

  async getSubscription(): Promise<SubscriptionCache | undefined> {
    return this.db!.get('subscription', 'current');
  }

  async clearSubscription(): Promise<void> {
    await this.db!.delete('subscription', 'current');
  }

  // 偏好操作
  async setPreference(key: string, value: any): Promise<void> {
    await this.db!.put('preferences', value, key);
  }

  async getPreference<T>(key: string, defaultValue?: T): Promise<T | undefined> {
    const val = await this.db!.get('preferences', key);
    return val !== undefined ? val : defaultValue;
  }
}

export const aetherDB = new AetherDB();
```

```typescript
// 文件：src/core/db/opfs.ts

class OPFSManager {
  private root: FileSystemDirectoryHandle | null = null;

  async init(): Promise<void> {
    this.root = await navigator.storage.getDirectory();
    // 确保基础目录存在
    await this.ensureDirectory('assets');
    await this.ensureDirectory('exports');
    await this.ensureDirectory('thumbnails');
    await this.ensureDirectory('temp');
  }

  private async ensureDirectory(path: string): Promise<FileSystemDirectoryHandle> {
    const parts = path.split('/');
    let dir = this.root!;
    for (const part of parts) {
      dir = await dir.getDirectoryHandle(part, { create: true });
    }
    return dir;
  }

  private async getDirectory(path: string): Promise<FileSystemDirectoryHandle> {
    const parts = path.split('/').filter(Boolean);
    let dir = this.root!;
    for (const part of parts) {
      dir = await dir.getDirectoryHandle(part, { create: true });
    }
    return dir;
  }

  /** 写入文件 */
  async writeFile(path: string, data: Blob | ArrayBuffer | string): Promise<void> {
    const parts = path.split('/');
    const fileName = parts.pop()!;
    const dirPath = parts.join('/');
    const dir = await this.getDirectory(dirPath);
    const fileHandle = await dir.getFileHandle(fileName, { create: true });
    const writable = await fileHandle.createWritable();
    await writable.write(data);
    await writable.close();
  }

  /** 读取文件为 Blob */
  async readFile(path: string): Promise<Blob> {
    const parts = path.split('/');
    const fileName = parts.pop()!;
    const dirPath = parts.join('/');
    const dir = await this.getDirectory(dirPath);
    const fileHandle = await dir.getFileHandle(fileName);
    return await fileHandle.getFile();
  }

  /** 读取文件为 ArrayBuffer */
  async readFileAsArrayBuffer(path: string): Promise<ArrayBuffer> {
    const blob = await this.readFile(path);
    return await blob.arrayBuffer();
  }

  /** 读取文件为 URL（用于 img/video 标签） */
  async readFileAsURL(path: string): Promise<string> {
    const blob = await this.readFile(path);
    return URL.createObjectURL(blob);
  }

  /** 删除文件 */
  async deleteFile(path: string): Promise<void> {
    const parts = path.split('/');
    const fileName = parts.pop()!;
    const dirPath = parts.join('/');
    const dir = await this.getDirectory(dirPath);
    await dir.removeEntry(fileName);
  }

  /** 检查文件是否存在 */
  async fileExists(path: string): Promise<boolean> {
    try {
      const parts = path.split('/');
      const fileName = parts.pop()!;
      const dirPath = parts.join('/');
      const dir = await this.getDirectory(dirPath);
      await dir.getFileHandle(fileName);
      return true;
    } catch {
      return false;
    }
  }

  /** 获取文件大小 */
  async getFileSize(path: string): Promise<number> {
    const blob = await this.readFile(path);
    return blob.size;
  }

  /** 列出目录内容 */
  async listDirectory(path: string): Promise<string[]> {
    const dir = await this.getDirectory(path);
    const names: string[] = [];
    for await (const name of dir.keys()) {
      names.push(name);
    }
    return names;
  }

  /** 清空目录 */
  async clearDirectory(path: string): Promise<void> {
    const dir = await this.getDirectory(path);
    for await (const name of dir.keys()) {
      await dir.removeEntry(name, { recursive: true });
    }
  }

  /** 计算目录总大小 */
  async getDirectorySize(path: string): Promise<number> {
    let total = 0;
    const dir = await this.getDirectory(path);
    for await (const [name, handle] of dir.entries()) {
      if (handle.kind === 'file') {
        const file = await (handle as FileSystemFileHandle).getFile();
        total += file.size;
      } else if (handle.kind === 'directory') {
        total += await this.getDirectorySize(`${path}/${name}`);
      }
    }
    return total;
  }
}

export const opfs = new OPFSManager();
```

```typescript
// 文件：src/core/db/storageManager.ts

class StorageManager {
  /** 获取当前已使用存储空间 */
  async getUsedSpace(): Promise<number> {
    if (navigator.storage && navigator.storage.estimate) {
      const estimate = await navigator.storage.estimate();
      return estimate.usage || 0;
    }
    // 降级方案：遍历 OPFS 计算
    return opfs.getDirectorySize('');
  }

  /** 获取可用存储空间配额 */
  async getQuota(): Promise<number> {
    if (navigator.storage && navigator.storage.estimate) {
      const estimate = await navigator.storage.estimate();
      return estimate.quota || 0;
    }
    return -1; // 未知
  }

  /** 检查是否有足够空间 */
  async hasEnoughSpace(requiredBytes: number): Promise<boolean> {
    const used = await this.getUsedSpace();
    const quota = await this.getQuota();
    if (quota <= 0) return true; // 无法获取配额时假设足够
    return used + requiredBytes < quota * 0.9; // 保留10%余量
  }

  /** 请求更多存储空间（Chrome 下会弹权限提示） */
  async requestMoreSpace(): Promise<boolean> {
    if (navigator.storage && navigator.storage.persist) {
      return await navigator.storage.persist();
    }
    return false;
  }

  /** 清理临时文件 */
  async cleanupTempFiles(): Promise<void> {
    await opfs.clearDirectory('temp');
    // 清理超过24小时的导出临时文件
    const exports = await opfs.listDirectory('exports');
    const now = Date.now();
    for (const name of exports) {
      const timestamp = parseInt(name.split('_')[1] || '0');
      if (now - timestamp > 24 * 60 * 60 * 1000) {
        await opfs.deleteFile(`exports/${name}`);
      }
    }
  }

  /** 清理未被引用的素材（垃圾回收） */
  async cleanupOrphanedAssets(projectId: string): Promise<void> {
    const assets = await aetherDB.getAssetsByProject(projectId);
    for (const asset of assets) {
      if (asset.refCount <= 0) {
        // 删除 OPFS 文件
        await opfs.deleteFile(asset.opfsPath);
        // 删除数据库记录
        await aetherDB.deleteAsset(asset.id);
      }
    }
  }
}

export const storageManager = new StorageManager();
```

```typescript
// 文件：src/core/project/exporter.ts

import JSZip from 'jszip';

class ProjectExporter {
  /**
   * 导出工程文件
   * @param projectId 工程ID
   * @param options 导出选项
   */
  async exportProject(
    projectId: string,
    options: {
      embedAssets: boolean;      // 是否内嵌素材文件
      includeThumbnail: boolean; // 是否包含缩略图
      compress: boolean;         // 是否压缩
    }
  ): Promise<Blob> {
    const project = await aetherDB.getProject(projectId);
    if (!project) throw new Error('工程不存在');

    const zip = new JSZip();

    // 1. 写入 project.json
    const projectJson = JSON.stringify(project.data, null, 2);
    zip.file('project.json', projectJson);

    // 2. 计算校验和
    const projectJsonHash = await this.sha256(projectJson);

    // 3. 处理素材
    let assetCount = 0;
    let totalAssetSize = 0;
    if (options.embedAssets) {
      const assets = await aetherDB.getAssetsByProject(projectId);
      const assetsFolder = zip.folder('assets')!;
      for (const asset of assets) {
        try {
          const blob = await opfs.readFile(asset.opfsPath);
          const ext = this.getExtensionFromMime(asset.mimeType);
          assetsFolder.file(`${asset.id}.${ext}`, blob);
          assetCount++;
          totalAssetSize += asset.size;
        } catch (e) {
          console.warn(`素材 ${asset.name} 导出失败:`, e);
        }
      }
    }

    // 4. 处理缩略图
    if (options.includeThumbnail && project.thumbnail) {
      // thumbnail 可能是 base64 或 OPFS 路径
      if (project.thumbnail.startsWith('data:')) {
        const thumbBlob = this.dataURLtoBlob(project.thumbnail);
        zip.file('thumbnail.png', thumbBlob);
      } else {
        try {
          const thumbBlob = await opfs.readFile(project.thumbnail);
          zip.file('thumbnail.png', thumbBlob);
        } catch (e) {
          console.warn('缩略图导出失败:', e);
        }
      }
    }

    // 5. 写入 manifest.json
    const manifest: ProjectManifest = {
      formatVersion: '1.0.0',
      appVersion: APP_VERSION,
      projectId: project.id,
      projectName: project.name,
      createdAt: project.createdAt,
      exportedAt: Date.now(),
      assetsEmbedded: options.embedAssets,
      assetCount,
      totalAssetSize,
      checksum: {
        algorithm: 'SHA-256',
        projectJson: projectJsonHash,
      },
      compression: {
        enabled: options.compress,
        algorithm: 'deflate',
      },
    };
    zip.file('manifest.json', JSON.stringify(manifest, null, 2));

    // 6. 生成 ZIP 文件
    const blob = await zip.generateAsync({
      type: 'blob',
      compression: options.compress ? 'DEFLATE' : 'STORE',
      compressionOptions: { level: 6 },
    });

    return blob;
  }

  /** 下载工程文件 */
  async downloadProject(projectId: string, options?: Partial<ExportOptions>): Promise<void> {
    const defaultOptions: ExportOptions = {
      embedAssets: true,
      includeThumbnail: true,
      compress: true,
    };
    const blob = await this.exportProject(projectId, { ...defaultOptions, ...options });
    const project = await aetherDB.getProject(projectId);
    const fileName = `${project?.name || 'project'}.aether`;
    this.downloadBlob(blob, fileName);
  }

  // ... 辅助方法（sha256、dataURLtoBlob、downloadBlob、getExtensionFromMime）
}
```

```typescript
// 文件：src/core/project/importer.ts

class ProjectImporter {
  /**
   * 导入工程文件
   * @param file .aether 文件
   * @returns 新工程ID
   */
  async importProject(file: File): Promise<string> {
    // 1. 读取并解析 ZIP
    const zip = await JSZip.loadAsync(file);

    // 2. 读取并验证 manifest
    const manifestFile = zip.file('manifest.json');
    if (!manifestFile) throw new Error('无效的工程文件：缺少 manifest.json');
    const manifest = JSON.parse(await manifestFile.async('string')) as ProjectManifest;

    // 验证格式版本兼容性
    if (!this.isVersionCompatible(manifest.formatVersion)) {
      throw new Error(`不支持的工程格式版本: ${manifest.formatVersion}`);
    }

    // 3. 读取 project.json
    const projectFile = zip.file('project.json');
    if (!projectFile) throw new Error('无效的工程文件：缺少 project.json');
    const projectJson = await projectFile.async('string');

    // 校验完整性（如果有校验和）
    if (manifest.checksum?.projectJson) {
      const actualHash = await this.sha256(projectJson);
      if (actualHash !== manifest.checksum.projectJson) {
        throw new Error('工程文件校验失败，文件可能已损坏');
      }
    }

    const projectData = JSON.parse(projectJson) as ProjectData;

    // 4. 数据迁移（如果旧版本）
    const migratedData = await this.migrateProjectData(projectData, manifest.formatVersion);

    // 5. 创建新工程
    const newProjectId = `proj_${Date.now()}`;
    const newProject: ProjectRecord = {
      id: newProjectId,
      name: `${manifest.projectName || '导入工程'} (导入)`,
      description: projectData.description,
      createdAt: Date.now(),
      updatedAt: Date.now(),
      version: manifest.formatVersion,
      data: migratedData,
      assetIds: [],
    };

    // 6. 导入素材（如果内嵌）
    if (manifest.assetsEmbedded) {
      const assetsFolder = zip.folder('assets');
      if (assetsFolder) {
        const assetIds: string[] = [];
        for (const [relativePath, fileHandle] of Object.entries(assetsFolder.files)) {
          if (fileHandle.dir) continue;
          try {
            const assetBlob = await fileHandle.async('blob');
            const assetId = await this.importAsset(assetBlob, newProjectId);
            assetIds.push(assetId);
          } catch (e) {
            console.warn(`素材 ${relativePath} 导入失败:`, e);
          }
        }
        newProject.assetIds = assetIds;
      }
    }

    // 7. 导入缩略图
    const thumbnailFile = zip.file('thumbnail.png');
    if (thumbnailFile) {
      const thumbBlob = await thumbnailFile.async('blob');
      const thumbPath = `thumbnails/${newProjectId}.png`;
      await opfs.writeFile(thumbPath, thumbBlob);
      newProject.thumbnail = thumbPath;
    }

    // 8. 保存工程
    await aetherDB.saveProject(newProject);

    // 9. 添加到最近工程
    await aetherDB.setPreference('lastProjectId', newProjectId);

    return newProjectId;
  }

  /** 导入单个素材 */
  private async importAsset(blob: Blob, projectId: string): Promise<string> {
    const assetId = `asset_${Date.now()}_${Math.random().toString(36).slice(2, 8)}`;
    const ext = this.getExtensionFromMime(blob.type);
    const opfsPath = `assets/${assetId}.${ext}`;

    // 写入 OPFS
    await opfs.writeFile(opfsPath, blob);

    // 计算哈希（异步，不阻塞）
    const hash = await this.sha256(await blob.arrayBuffer());

    // 创建素材记录
    const asset: AssetRecord = {
      id: assetId,
      projectId,
      name: `导入素材_${assetId.slice(-6)}`,
      type: this.detectAssetType(blob.type),
      mimeType: blob.type,
      size: blob.size,
      hash,
      opfsPath,
      createdAt: Date.now(),
      lastUsedAt: Date.now(),
      refCount: 1,
    };

    await aetherDB.saveAsset(asset);
    return assetId;
  }

  // ... 辅助方法
}
```

```typescript
// 文件：src/core/assets/importer.ts

class AssetImporter {
  /** 支持的文件类型白名单 */
  private readonly ACCEPTED_TYPES: Record<AssetType, string[]> = {
    image: ['image/jpeg', 'image/png', 'image/webp', 'image/gif'],
    'panorama-img': ['image/jpeg', 'image/png', 'image/webp'],
    video: ['video/mp4', 'video/webm', 'video/ogg'],
    'panorama-vid': ['video/mp4', 'video/webm'],
    'model-3d': ['model/gltf-binary', 'model/gltf+json', 'application/octet-stream'],
    'gaussian-splat': ['application/octet-stream', 'text/plain'],
    audio: ['audio/mpeg', 'audio/wav', 'audio/ogg'],
    font: ['font/ttf', 'font/otf', 'font/woff', 'font/woff2'],
  };

  /**
   * 导入素材文件
   * @param file 原始文件
   * @param projectId 所属工程ID
   * @param expectedType 期望的素材类型（可选，自动检测）
   */
  async importAsset(
    file: File,
    projectId: string,
    expectedType?: AssetType
  ): Promise<AssetRecord> {
    // ① 文件类型校验
    const detectedType = expectedType || this.detectAssetType(file.type, file.name);
    if (!this.isTypeAccepted(detectedType, file.type)) {
      throw new Error(`不支持的文件类型: ${file.type}`);
    }

    // ② 存储空间检查
    const hasSpace = await storageManager.hasEnoughSpace(file.size);
    if (!hasSpace) {
      const granted = await storageManager.requestMoreSpace();
      if (!granted) {
        throw new Error('存储空间不足，请清理旧素材或授权更多存储空间');
      }
    }

    // ③ 计算文件哈希
    const arrayBuffer = await file.arrayBuffer();
    const hash = await this.sha256(arrayBuffer);

    // ④ 哈希去重检查
    const existing = await aetherDB.getAssetByHash(hash);
    if (existing && existing.projectId === projectId) {
      // 同工程内已存在相同文件，复用
      existing.refCount++;
      existing.lastUsedAt = Date.now();
      await aetherDB.saveAsset(existing);
      return existing;
    }

    // ⑤ 写入 OPFS
    const assetId = `asset_${Date.now()}_${Math.random().toString(36).slice(2, 8)}`;
    const ext = this.getExtension(file.name, file.type);
    const opfsPath = `assets/${assetId}.${ext}`;
    await opfs.writeFile(opfsPath, file);

    // ⑥ 提取元数据
    const metadata = await this.extractMetadata(file, detectedType);

    // ⑦ 创建素材记录并保存
    const asset: AssetRecord = {
      id: assetId,
      projectId,
      name: file.name,
      type: detectedType,
      mimeType: file.type,
      size: file.size,
      hash,
      opfsPath,
      ...metadata,
      createdAt: Date.now(),
      lastUsedAt: Date.now(),
      refCount: 1,
    };
    await aetherDB.saveAsset(asset);

    return asset;
  }

  /** 批量导入素材 */
  async importAssets(
    files: FileList | File[],
    projectId: string,
    onProgress?: (current: number, total: number, asset?: AssetRecord) => void
  ): Promise<AssetRecord[]> {
    const fileArray = Array.from(files);
    const results: AssetRecord[] = [];
    for (let i = 0; i < fileArray.length; i++) {
      try {
        const asset = await this.importAsset(fileArray[i], projectId);
        results.push(asset);
        onProgress?.(i + 1, fileArray.length, asset);
      } catch (e) {
        console.error(`素材 ${fileArray[i].name} 导入失败:`, e);
        onProgress?.(i + 1, fileArray.length);
      }
    }
    return results;
  }

  /** 提取素材元数据 */
  private async extractMetadata(file: File, type: AssetType): Promise<Partial<AssetRecord>> {
    const meta: Partial<AssetRecord> = {};

    if (type === 'image' || type === 'panorama-img') {
      const img = await this.loadImage(file);
      meta.width = img.width;
      meta.height = img.height;
    }

    if (type === 'video' || type === 'panorama-vid') {
      const video = await this.loadVideo(file);
      meta.width = video.videoWidth;
      meta.height = video.videoHeight;
      meta.duration = video.duration;
    }

    return meta;
  }

  // ... 辅助方法
}
```

```typescript
// 文件：src/core/assets/loader.ts

class AssetLoader {
  /** URL 缓存：assetId -> objectURL */
  private urlCache = new Map<string, string>();
  /** 引用计数：assetId -> 被引用次数 */
  private refCounts = new Map<string, number>();

  /**
   * 获取素材的可访问 URL
   * 用于 img/video/audio 标签的 src 属性
   */
  async getAssetURL(assetId: string): Promise<string> {
    // 检查缓存
    if (this.urlCache.has(assetId)) {
      const url = this.urlCache.get(assetId)!;
      this.refCounts.set(assetId, (this.refCounts.get(assetId) || 0) + 1);
      return url;
    }

    // 从数据库获取素材记录
    const asset = await aetherDB.getAsset(assetId);
    if (!asset) throw new Error(`素材不存在: ${assetId}`);

    // 从 OPFS 读取文件并创建 ObjectURL
    const blob = await opfs.readFile(asset.opfsPath);
    const url = URL.createObjectURL(blob);

    // 缓存
    this.urlCache.set(assetId, url);
    this.refCounts.set(assetId, 1);

    return url;
  }

  /** 释放素材 URL（不再使用时调用，释放内存） */
  releaseAssetURL(assetId: string): void {
    const count = (this.refCounts.get(assetId) || 0) - 1;
    if (count <= 0) {
      const url = this.urlCache.get(assetId);
      if (url) {
        URL.revokeObjectURL(url);
        this.urlCache.delete(assetId);
      }
      this.refCounts.delete(assetId);
    } else {
      this.refCounts.set(assetId, count);
    }
  }

  /** 预加载素材（提前加载到缓存，提升编辑流畅度） */
  async preloadAssets(assetIds: string[]): Promise<void> {
    await Promise.all(
      assetIds.map(async (id) => {
        try {
          await this.getAssetURL(id);
        } catch (e) {
          console.warn(`预加载素材失败: ${id}`, e);
        }
      })
    );
  }

  /** 清理所有缓存（切换工程时调用） */
  clearCache(): void {
    for (const url of this.urlCache.values()) {
      URL.revokeObjectURL(url);
    }
    this.urlCache.clear();
    this.refCounts.clear();
  }

  /** 获取素材 Blob（用于导出、上传等） */
  async getAssetBlob(assetId: string): Promise<Blob> {
    const asset = await aetherDB.getAsset(assetId);
    if (!asset) throw new Error(`素材不存在: ${assetId}`);
    return opfs.readFile(asset.opfsPath);
  }
}

export const assetLoader = new AssetLoader();
```

```typescript
class AssetGarbageCollector {
  /**
   * 删除素材引用（元素被删除时调用）
   * 如果 refCount 降为 0，则标记为可回收
   */
  async releaseAsset(assetId: string, projectId: string): Promise<void> {
    const asset = await aetherDB.getAsset(assetId);
    if (!asset) return;

    asset.refCount = Math.max(0, asset.refCount - 1);
    asset.lastUsedAt = Date.now();
    await aetherDB.saveAsset(asset);
  }

  /** 永久删除素材（用户手动删除，或工程删除时清理） */
  async deleteAssetPermanently(assetId: string): Promise<void> {
    const asset = await aetherDB.getAsset(assetId);
    if (!asset) return;

    // 释放 URL 缓存
    assetLoader.releaseAssetURL(assetId);

    // 删除 OPFS 文件
    try {
      await opfs.deleteFile(asset.opfsPath);
    } catch (e) {
      console.warn(`删除素材文件失败: ${asset.opfsPath}`, e);
    }

    // 删除数据库记录
    await aetherDB.deleteAsset(assetId);
  }

  /** 清理工程中所有未被引用的素材 */
  async cleanupOrphanedAssets(projectId: string): Promise<number> {
    const assets = await aetherDB.getAssetsByProject(projectId);
    let cleanedCount = 0;

    for (const asset of assets) {
      if (asset.refCount <= 0) {
        // 检查是否真的未被工程数据引用（双重验证）
        const project = await aetherDB.getProject(projectId);
        if (project && !this.isAssetReferenced(asset.id, project.data)) {
          await this.deleteAssetPermanently(asset.id);
          cleanedCount++;
        }
      }
    }

    return cleanedCount;
  }

  /** 检查素材是否被工程数据引用（遍历所有元素的 refId） */
  private isAssetReferenced(assetId: string, projectData: ProjectData): boolean {
    for (const scene of Object.values(projectData.scenes)) {
      for (const element of scene.els) {
        if (element.refId === assetId) return true;
        // 检查热点中的媒体引用
        if (element.hotspots) {
          for (const hotspot of element.hotspots) {
            if (hotspot.mediaRefId === assetId) return true;
            if (hotspot.iconImageRefId === assetId) return true;
            if (hotspot.iconVideoRefId === assetId) return true;
          }
        }
      }
    }
    // 检查全局素材
    if (projectData.globalAssets) {
      for (const ga of projectData.globalAssets) {
        if (ga.refId === assetId) return true;
      }
    }
    return false;
  }

  /** 获取工程素材使用统计 */
  async getAssetStats(projectId: string): Promise<{
    total: number;
    referenced: number;
    orphaned: number;
    totalSize: number;
    orphanedSize: number;
  }> {
    const assets = await aetherDB.getAssetsByProject(projectId);
    let referenced = 0;
    let orphaned = 0;
    let totalSize = 0;
    let orphanedSize = 0;

    for (const asset of assets) {
      totalSize += asset.size;
      if (asset.refCount > 0) {
        referenced++;
      } else {
        orphaned++;
        orphanedSize += asset.size;
      }
    }

    return {
      total: assets.length,
      referenced,
      orphaned,
      totalSize,
      orphanedSize,
    };
  }
}
```

```typescript
interface FeatureRule {
  feature: FeatureKey;
  free: boolean;    // 免费版是否可用
  pro: boolean;     // 专业版是否可用
  team: boolean;    // 团队版是否可用

const FEATURE_RULES: FeatureRule[] = [
  { feature: 'export_image', free: true, pro: true, team: true },
  { feature: 'export_video', free: false, pro: true, team: true },
  { feature: 'export_html', free: true, pro: true, team: true },

  { feature: 'ai_assistant', free: false, pro: true, team: true },
  { feature: 'team_collaboration', free: false, pro: false, team: true },
  { feature: 'no_ads', free: false, pro: true, team: true },
];

class FeatureGate {
  private currentPlan: 'free' | 'pro' | 'team' = 'free';
  private usageCache = new Map<FeatureKey, number>();

  /** 初始化（从本地缓存加载订阅状态） */
  async init(): Promise<void> {
    const sub = await aetherDB.getSubscription();
    if (sub && sub.status === 'active') {
      this.currentPlan = sub.plan;
    }
  }

  /** 检查功能是否可用 */
  canUse(feature: FeatureKey): boolean {
    const rule = FEATURE_RULES.find(r => r.feature === feature);
    if (!rule) return false;
    return rule[this.currentPlan];
  }

  /** 检查功能是否可用，并返回限制信息 */
  check(feature: FeatureKey): {
    allowed: boolean;
    reason?: string;
    current?: number;
    limit?: number;
  } {
    const rule = FEATURE_RULES.find(r => r.feature === feature);
    if (!rule) return { allowed: false, reason: '未知功能' };

    if (!rule[this.currentPlan]) {
      return {
        allowed: false,
        reason: `该功能需要${this.getPlanName(this.currentPlan === 'free' ? 'pro' : this.currentPlan)}及以上版本`,
      };
    }

    // 检查数量限制
    if (rule.limit && rule.limit[this.currentPlan] !== undefined) {
      const limit = rule.limit[this.currentPlan]!;
      const current = this.usageCache.get(feature) || 0;
      if (current >= limit) {
        return {
          allowed: false,
          reason: `已达到使用上限（${limit}次）`,
          current,
          limit,
        };
      }
    }

    return { allowed: true };
  }

  /** 记录功能使用次数 */
  recordUsage(feature: FeatureKey): void {
    const current = this.usageCache.get(feature) || 0;
    this.usageCache.set(feature, current + 1);
  }

  /** 获取当前订阅计划 */
  getCurrentPlan(): 'free' | 'pro' | 'team' {
    return this.currentPlan;
  }

  /** 更新订阅状态（登录/验证后调用） */
  updatePlan(plan: 'free' | 'pro' | 'team'): void {
    this.currentPlan = plan;
  }

  /** 显示升级弹窗 */
  showUpgradeModal(feature: FeatureKey): void {
    // 触发 UI 层显示升级弹窗
    const event = new CustomEvent('aether:show-upgrade', {
      detail: { feature, plan: this.currentPlan },
    });
    window.dispatchEvent(event);
  }

  private getPlanName(plan: string): string {
    const names: Record<string, string> = {
      free: '免费版',
      pro: '专业版',
      team: '团队版',
    };
    return names[plan] || plan;
  }
}
```

### 5.3 订阅验证流程

```
用户打开编辑器
      │
      ▼
  ① 检查本地订阅缓存
      │
      ├── 缓存存在且未过期（7天内）→ 使用缓存，离线可用
      │
      └── 缓存不存在或已过期 → 继续
      │
      ▼
  ② 向服务器发起验证请求（带用户token）
      │
      ├── 验证成功 → 更新本地缓存，使用服务器返回的订阅状态
      │
      ├── 验证失败（网络错误）→ 使用本地缓存（如有），标记为"离线模式"
      │
      └── 验证失败（订阅过期）→ 降级为免费版，清除缓存
      │
      ▼
  ③ 关键操作时二次验证（导出、发布等）
      │
      ├── 本地缓存有效 → 直接放行
      │
      └── 本地缓存即将过期（<24小时）→ 后台静默刷新
```

### 5.4 订阅验证实现

```typescript
// 文件：src/core/auth/subscription.ts

class SubscriptionManager {
  private readonly CACHE_DURATION = 7 * 24 * 60 * 60 * 1000; // 7天
  private readonly REFRESH_THRESHOLD = 24 * 60 * 60 * 1000;   // 24小时内刷新
  private isRefreshing = false;

  /** 验证订阅状态（启动时调用） */
  async verifySubscription(userId?: string): Promise<SubscriptionCache> {
    // ① 检查本地缓存
    const cached = await aetherDB.getSubscription();
    if (cached && this.isCacheValid(cached)) {
      // 缓存有效，检查是否需要后台刷新
      if (this.needsRefresh(cached)) {
        this.backgroundRefresh(userId);
      }
      featureGate.updatePlan(cached.plan);
      return cached;
    }

    // ② 向服务器验证
    try {
      const result = await this.verifyWithServer(userId);
      const cache: SubscriptionCache = {
        userId: result.userId,
        plan: result.plan,
        status: result.status,
        expiresAt: result.expiresAt,
        cachedAt: Date.now(),
        features: result.features,
      };
      await aetherDB.saveSubscription(cache);
      featureGate.updatePlan(cache.plan);
      return cache;
    } catch (e) {
      // 网络错误，使用缓存降级
      if (cached) {
        console.warn('订阅验证失败，使用本地缓存:', e);
        featureGate.updatePlan(cached.plan);
        return cached;
      }
      // 无缓存，降级为免费版
      const freeCache: SubscriptionCache = {
        userId: userId || 'anonymous',
        plan: 'free',
        status: 'active',
        expiresAt: Date.now() + this.CACHE_DURATION,
        cachedAt: Date.now(),
        features: {},
      };
      featureGate.updatePlan('free');
      return freeCache;
    }
  }

  /** 关键操作前二次验证 */
  async verifyBeforeAction(action: string): Promise<boolean> {
    const cached = await aetherDB.getSubscription();
    if (!cached) return false;

    // 检查功能权限
    const feature = this.mapActionToFeature(action);
    const check = featureGate.check(feature);
    if (!check.allowed) {
      featureGate.showUpgradeModal(feature);
      return false;
    }

    // 如果缓存即将过期，后台刷新
    if (this.needsRefresh(cached) && !this.isRefreshing) {
      this.backgroundRefresh(cached.userId);
    }

    return true;
  }

  /** 向服务器验证 */
  private async verifyWithServer(userId?: string): Promise<ServerSubscriptionResult> {
    const token = await this.getAuthToken();
    const response = await fetch(`${API_BASE}/api/subscription/verify`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`,
      },
      body: JSON.stringify({ userId, appVersion: APP_VERSION }),
    });

    if (!response.ok) {
      throw new Error(`验证失败: ${response.status}`);
    }

    return await response.json();
  }

  /** 后台静默刷新 */
  private async backgroundRefresh(userId?: string): Promise<void> {
    if (this.isRefreshing) return;
    this.isRefreshing = true;
    try {
      const result = await this.verifyWithServer(userId);
      const cache: SubscriptionCache = {
        userId: result.userId,
        plan: result.plan,
        status: result.status,
        expiresAt: result.expiresAt,
        cachedAt: Date.now(),
        features: result.features,
      };
      await aetherDB.saveSubscription(cache);
      featureGate.updatePlan(cache.plan);
    } catch (e) {
      console.warn('后台刷新订阅失败:', e);
    } finally {
      this.isRefreshing = false;
    }
  }

  /** 检查缓存是否有效 */
  private isCacheValid(cache: SubscriptionCache): boolean {
    if (cache.status !== 'active') return false;
    if (Date.now() > cache.expiresAt) return false;
    if (Date.now() - cache.cachedAt > this.CACHE_DURATION) return false;
    return true;
  }

  /** 检查是否需要刷新 */
  private needsRefresh(cache: SubscriptionCache): boolean {
    return Date.now() - cache.cachedAt > this.REFRESH_THRESHOLD;
  }

  /** 登出时清除订阅缓存 */
  async clearSubscription(): Promise<void> {
    await aetherDB.clearSubscription();
    featureGate.updatePlan('free');
  }

  // ... 辅助方法
}

export const subscriptionManager = new SubscriptionManager();
```

### 5.5 防绕过机制

| 机制 | 说明 | 实现位置 |
|------|------|----------|
| **关键操作服务端验证** | 导出、发布等操作必须向服务器发请求验证订阅状态，服务器返回水印参数或授权令牌 | 导出模块 |
| **前端代码混淆** | 使用 javascript-obfuscator 混淆生产环境代码，增加逆向难度 | 构建配置 |
| **权限校验分散** | 不把权限判断集中在一个函数，而是在各个关键操作点分别校验 | 各功能模块 |

| **导出文件嵌入授权信息** | 导出的文件中嵌入用户ID和授权状态水印，便于追溯 | 导出模块 |

```typescript
class WatermarkManager {
  /**
   * 为 Canvas 添加水印
   * @param canvas 目标 Canvas
   * @param options 水印选项
   */
  applyWatermarkToCanvas(
    canvas: HTMLCanvasElement,
    options: {
      text?: string;
      position?: 'bottom-left' | 'bottom-right' | 'top-left' | 'top-right' | 'center';
      opacity?: number;
      fontSize?: number;
      fontFamily?: string;
      color?: string;
    } = {}
  ): void {
    const ctx = canvas.getContext('2d');
    if (!ctx) return;

    const {
      text = 'AETHER 免费版',
      position = 'bottom-right',
      opacity = 0.3,
      fontSize = 24,
      fontFamily = 'Arial, sans-serif',
      color = '#ffffff',
    } = options;

    ctx.save();
    ctx.globalAlpha = opacity;
    ctx.font = `${fontSize}px ${fontFamily}`;
    ctx.fillStyle = color;
    ctx.textBaseline = 'bottom';

    // 添加文字阴影增加可读性
    ctx.shadowColor = 'rgba(0,0,0,0.5)';
    ctx.shadowBlur = 4;
    ctx.shadowOffsetX = 1;
    ctx.shadowOffsetY = 1;

    const padding = 20;
    const textWidth = ctx.measureText(text).width;
    const textHeight = fontSize;

    let x: number, y: number;
    switch (position) {
      case 'bottom-left':
        x = padding;
        y = canvas.height - padding;
        break;
      case 'bottom-right':
        x = canvas.width - textWidth - padding;
        y = canvas.height - padding;
        break;
      case 'top-left':
        x = padding;
        y = textHeight + padding;
        break;
      case 'top-right':
        x = canvas.width - textWidth - padding;
        y = textHeight + padding;
        break;
      case 'center':
        x = (canvas.width - textWidth) / 2;
        y = (canvas.height + textHeight) / 2;
        break;
    }

    ctx.fillText(text, x, y);
    ctx.restore();

    // 隐写用户ID（不可见水印，用于追溯）
    this.embedHiddenWatermark(ctx, canvas);
  }

  /**
   * 隐写用户ID到图片（修改最低有效位）
   * 用于追溯盗版来源，肉眼不可见
   */
  private embedHiddenWatermark(ctx: CanvasRenderingContext2D, canvas: HTMLCanvasElement): void {
    try {
      const userId = this.getCurrentUserId();
      if (!userId) return;

      const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
      const data = imageData.data;
      const binary = this.stringToBinary(userId);

      // 在图片前 N 个像素的蓝色通道最低位写入数据
      let bitIndex = 0;
      for (let i = 0; i < data.length && bitIndex < binary.length; i += 4) {
        // 只修改蓝色通道（索引 i+2）的最低位
        data[i + 2] = (data[i + 2] & 0xFE) | (parseInt(binary[bitIndex], 2));
        bitIndex++;
      }

      ctx.putImageData(imageData, 0, 0);
    } catch (e) {
      console.warn('隐写水印失败:', e);
    }
  }

  /** 为视频帧添加水印（Canvas 渲染时调用） */
  applyWatermarkToVideoFrame(
    ctx: CanvasRenderingContext2D,
    width: number,
    height: number,
    frameIndex: number
  ): void {
    // 视频水印：全程显示 + 开头结尾5秒加强
    const isIntro = frameIndex < 150; // 假设30fps，5秒=150帧
    const isOutro = false; // 结尾由导出器单独处理

    const opacity = isIntro ? 0.6 : 0.3;
    const fontSize = isIntro ? 32 : 24;

    this.applyWatermarkToCanvas(ctx.canvas, {
      text: 'AETHER 免费版',
      position: 'bottom-right',
      opacity,
      fontSize,
    });
  }

  /** 生成视频片头（免费版） */
  async generateVideoIntro(
    width: number,
    height: number,
    duration: number = 5
  ): Promise<Blob> {
    const canvas = document.createElement('canvas');
    canvas.width = width;
    canvas.height = height;
    const ctx = canvas.getContext('2d')!;

    // 黑色背景
    ctx.fillStyle = '#000000';
    ctx.fillRect(0, 0, width, height);

    // 品牌文字
    ctx.fillStyle = '#ffffff';
    ctx.font = `bold ${Math.floor(height * 0.08)}px Arial`;
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.fillText('AETHER', width / 2, height / 2 - 30);

    ctx.font = `${Math.floor(height * 0.03)}px Arial`;
    ctx.fillStyle = '#888888';
    ctx.fillText('免费版 · 升级专业版去除片头', width / 2, height / 2 + 30);

    // 使用 MediaRecorder 录制视频
    const stream = canvas.captureStream(30);
    const recorder = new MediaRecorder(stream, { mimeType: 'video/webm' });
    const chunks: Blob[] = [];

    return new Promise((resolve) => {
      recorder.ondataavailable = (e) => chunks.push(e.data);
      recorder.onstop = () => resolve(new Blob(chunks, { type: 'video/webm' }));
      recorder.start();

      // 持续绘制 duration 秒
      const start = Date.now();
      const draw = () => {
        if (Date.now() - start < duration * 1000) {
          requestAnimationFrame(draw);
        } else {
          recorder.stop();
        }
      };
      draw();
    });
  }

}
```

```typescript
import { FastifyInstance, FastifyRequest, FastifyReply } from 'fastify';

export async function subscriptionRoutes(app: FastifyInstance) {
  // 验证订阅状态
  app.post('/api/subscription/verify', async (request: FastifyRequest, reply: FastifyReply) => {
    const userId = request.user?.id;
    if (!userId) {
      return reply.code(401).send({ error: '未登录' });
    }

    // 从数据库获取用户
    const user = await db.query('SELECT * FROM users WHERE id = $1', [userId]);
    if (user.rows.length === 0) {
      return reply.code(404).send({ error: '用户不存在' });
    }

    const u = user.rows[0];

    // 检查订阅是否过期
    let plan = u.plan;
    let status = u.plan_status;
    let expiresAt = u.plan_expires_at;

    if (plan !== 'free' && expiresAt && new Date(expiresAt) < new Date()) {
      // 订阅过期，降级为免费版
      plan = 'free';
      status = 'expired';
      expiresAt = null;
      await db.query(
        'UPDATE users SET plan = $1, plan_status = $2, plan_expires_at = $3 WHERE id = $4',
        ['free', 'expired', null, userId]
      );
    }

    // 生成签名的订阅状态（防止前端篡改）
    const payload = {
      userId,
```

## 10. 关键技术难点与解决方案

### 10.1 OPFS 浏览器兼容性

**问题**：OPFS 在旧版浏览器（如 Safari 16.4 以下、Firefox 111 以下）不支持。

**解决方案**：
```typescript
// 特性检测 + 降级方案
class StorageAdapter {
  private opfsSupported = false;

  async init(): Promise<void> {
    try {
      if (navigator.storage && navigator.storage.getDirectory) {
        // 测试是否真的可用（某些浏览器声明支持但实际有bug）
        const dir = await navigator.storage.getDirectory();
        this.opfsSupported = true;
      }
    } catch (e) {
      this.opfsSupported = false;
    }
  }

  async writeFile(path: string, data: Blob): Promise<void> {
    if (this.opfsSupported) {
      return opfs.writeFile(path, data);
    } else {
      // 降级到 IndexedDB 存文件
      return this.writeToIndexedDB(path, data);
    }
  }
}
```

### 10.2 大文件导入性能

**问题**：视频文件（几百MB）、高斯泼溅文件（几百MB）导入时计算哈希会阻塞主线程。

**解决方案**：
- 使用 Web Worker 在后台线程计算哈希
- 使用流式读取（File.stream()），不一次性加载到内存
- 显示导入进度条

```typescript
// Web Worker 中计算 SHA-256
async function hashFileInWorker(file: File): Promise<string> {
  const worker = new Worker('/hash-worker.js');
  return new Promise((resolve, reject) => {
    worker.onmessage = (e) => resolve(e.data);
    worker.onerror = reject;
    worker.postMessage(file);
  });
}
```

### 10.3 内存管理

**问题**：浏览器内存有限（通常4-8GB），同时加载多个4K全景图+3D模型会崩溃。

**解决方案**：
- 素材懒加载：只加载当前场景需要的素材
- 场景切换时释放上一场景的纹理和URL
- 限制同时加载的素材数量（如最多5个）
- 大文件使用低清预览，导出时才用原图
- 监听 `performance.memory`，接近上限时主动释放

```typescript
class MemoryManager {
  private readonly MAX_CONCURRENT_ASSETS = 5;
  private loadedAssets = new Map<string, number>(); // assetId -> 最后使用时间

  /** 检查内存使用情况，必要时释放旧素材 */
  checkAndRelease(): void {
    // Chrome 特有 API
    if (performance.memory) {
      const usage = performance.memory.usedJSHeapSize / performance.memory.jsHeapSizeLimit;
      if (usage > 0.8) {
        // 释放最久未使用的素材
        this.releaseOldestAssets(2);
      }
    }
  }

  /** 释放最久未使用的素材 */
  private releaseOldestAssets(count: number): void {
    const sorted = Array.from(this.loadedAssets.entries())
      .sort((a, b) => a[1] - b[1]);
    for (let i = 0; i < Math.min(count, sorted.length); i++) {
      assetLoader.releaseAssetURL(sorted[i][0]);
      this.loadedAssets.delete(sorted[i][0]);
    }
  }
}
```

### 10.4 付费验证防绕过

**问题**：前端代码可被用户通过浏览器控制台修改，绕过付费限制。

**解决方案**（多层防护）：
1. **关键操作服务端验证**：导出、发布等操作必须向服务器发请求，服务器返回水印参数或授权令牌
2. **导出文件嵌入授权信息**：导出的图片/视频/HTML中嵌入用户ID水印（可见+隐写），便于追溯盗版
3. **代码混淆**：生产环境使用 javascript-obfuscator，控制流平坦化+字符串加密
4. **运行时完整性检查**：定期检查关键函数的 toString 是否被篡改
5. **服务端异常检测**：检测同一账号多IP同时导出、短时间大量导出等异常行为

### 10.5 HTML 包导出性能

**问题**：工程包含多个大视频时，内嵌为 base64 会导致 HTML 文件过大（几百MB），打开慢。

**解决方案**：
- 默认多文件模式（ZIP包），素材单独存放
- 单文件模式仅适用于小工程（总素材<50MB）
- 大文件使用外部资源引用（相对路径），不内嵌
- 导出时显示进度条和预计文件大小
