# 修复记录 · 第十一批（控制桥命令回执 + 新增/删除图层）

## 1. 命令回执

之前 MCP 下发命令后只能知道「已发送」，不知道编辑器是否真的执行。现在：

- 编辑器执行完命令后 POST `/api/control/result`（`{id, ok, message}`）
- 服务端用 `pendingCommands` 把回执与命令 id 关联，最长等待 5 秒（可用 `timeoutMs` 调整）
- MCP 收到的返回从 `{ok:true, delivered:1}` 变成：

```json
{
  "id": "215edfc4-...",
  "delivered": 1,
  "ok": true,
  "acknowledged": true,
  "message": "已更新图层 s1_hero_title"
}
```

失败时 `ok:false` + 具体错误（例如 `场景不存在：xxx`、`不支持的命令：xxx`）。
超时返回 `acknowledged:false`，并提示「命令已下发，编辑器未在时限内回执」，不会误报成功。

## 2. 新增命令

| 命令 | 参数 | 说明 |
|---|---|---|
| `add_text_layer` | `sceneId`、`text`、`x/y/w/h`（百分比）、`fontSize` | 新建文本图层并自动选中 |
| `delete_element` | `sceneId`、`elementId` | 删除指定图层 |

对应 MCP 工具：`editor_add_text_layer`、`editor_delete_element`（MCP 工具总数 12 个）。
