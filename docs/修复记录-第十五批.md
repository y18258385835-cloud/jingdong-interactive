# 修复记录 · 第十五批（控制桥导出落盘）

## 1. 导出成品可写入本机目录

之前 `editor_export` 只能触发浏览器下载，MCP 拿不到文件本体。现在新增落盘通道：

```
编辑器导出 Blob → POST /api/control/export（base64） → 本机服务写入 data/exports/ → 返回绝对路径
```

- 新接口：`POST /api/control/export`，需要控制令牌，仅 loopback
- 文件大小上限 200 MB
- 文件名清洗：去掉 `\ / : * ? " < > |` 与控制字符、去掉前导点，最长 160 字符，避免路径穿越
- 输出目录：`<repo>/data/exports/`（已加入 `.gitignore`）

MCP `editor_export` 新增参数：

| 参数 | 说明 |
|---|---|
| `saveToHost: true` | 写入本机目录，回执返回绝对路径（不触发浏览器下载） |
| `saveToHost: false`（默认） | 保持原行为，浏览器下载 |

## 2. 端到端验收


## 4. 安全说明

- 落盘接口同样要求 `X-Control-Token`，且只接受 loopback 与本地 Origin
- 只允许写入固定的 `data/exports/` 目录，文件名经过清洗，不能指定路径
- 建议后续增加「单次会话导出数量上限」，避免被脚本反复写入占满磁盘
