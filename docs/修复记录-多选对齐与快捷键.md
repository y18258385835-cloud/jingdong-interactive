# 多选对齐、等距分布与快捷键修复记录

> 目标：像墨刀/PPT 一样，选中多个图层后能一键对齐、等距分布；快捷键面板里写了的键必须真的能用，改键后立即生效。

## 原来的问题

1. **多选只能一起拖，不能对齐/等距**
   选中多个图层后，画面只显示主选图层的单选框，其他图层没有明确轮廓；没有左/中/右/上/中/下对齐，也没有水平/垂直等距。

2. **快捷键是“装饰品”**
   `ShortcutsManager.tsx` 里早就有 `Ctrl+Shift+L/C/R/T/M/B` 这些对齐快捷键，但 `CanvasViewport.tsx` 的键盘处理只实现了工具切换和方向键微调，按了没反应。

3. **改键不生效**
   快捷键设置面板能改键，但没有命令注册表，画布实际执行的还是写死的键位。

## 修复内容

### 1. 对齐/分布算法（可单测）

新增 `src/utils/alignment.ts`：

- 6 种对齐：左、水平居中、右、顶、垂直居中、底；
- 2 种等距分布：水平、垂直；
- 多选时按选区包围盒对齐；单选时对齐画布；
- 等距分布保持首尾图层不动，中间图层按相等间距排开；
- 锁定图层不参与移动；
- 结果自动限制在画布内，保留 2 位小数；
- 只返回位置发生变化的图层，方便批量提交。

### 2. 多选浮条与多选框

`src/components/CanvasViewport.tsx`：

- 多选时显示一个统一的蓝色包围框；
- 每个选中图层显示细轮廓；
- 多选时隐藏单个图层的缩放手柄，避免误改其中一个；
- 包围框上方显示操作条：`3 项` + 6 个对齐 + 2 个等距按钮；
- 浮条靠右时自动右对齐，避免被画布裁掉；
- 浮条带 `data-aether-multi-toolbar`，画布捕获层会跳过它，不会误拖下面的图层。

### 3. 快捷键真正生效

新增 `src/utils/shortcutKeys.ts`：

- 统一把 `Ctrl / Cmd / Command / Meta`、`Alt / Option`、`Shift` 归一化；
- 把 `Space`、`Arrow`、`Delete`、`F1` 等键名统一；
- 画布只维护一份“命令 ID → 快捷键”的映射，快捷键设置面板保存后立即刷新。

默认键位改成 `Ctrl+Alt`，避开浏览器自带的 `Ctrl+Shift+R`（强制刷新）、`Ctrl+Shift+T`（重开标签页）等冲突：

| 命令 | 默认快捷键 |
|---|---|
| 左对齐 | `Ctrl+Alt+L` |
| 水平居中 | `Ctrl+Alt+C` |
| 右对齐 | `Ctrl+Alt+R` |
| 顶对齐 | `Ctrl+Alt+T` |
| 垂直居中 | `Ctrl+Alt+M` |
| 底对齐 | `Ctrl+Alt+B` |
| 水平等距 | `Ctrl+Alt+H` |
| 垂直等距 | `Ctrl+Alt+V` |

- `ShortcutsManager.tsx` 增加“水平/垂直等距”两个可配置命令；
- `ShortcutsModal.tsx` 增加「对齐与分布」快捷键说明；
- 改键后不需要刷新页面，下一次按键立即生效。

### 4. 历史记录

- 对齐/分布只记 **一条** 历史；
- 批量更新后等 React 提交完再写快照，撤销能一次恢复到操作前；
- 锁定图层被跳过。

## 实测结果

用首页三张功能卡片 `s1_feat_1 / s1_feat_2 / s1_feat_3` 验证：

### 左对齐 + 撤销

```
操作前：424.8 / 565.2 / 705.6
Ctrl+Alt+L 后：424.8 / 424.8 / 424.8
Ctrl+Z 后：424.8 / 565.2 / 705.6
```

### 改键立即生效

把「左对齐」改成 `Ctrl+Alt+J`，不刷新页面直接按：

```
Ctrl+Alt+J 后：424.8 / 424.8 / 424.8
```

### 水平等距

先把第三张卡片单独向右移，形成明显大间距，再点「水平等距」：

```
操作前：424.8 / 424.8 / 825.9
操作后：424.8 / 625.4 / 825.9
间距：72.3px / 72.2px
```
