# 修复记录 · 第二十四批（自动更新 + MP4 导出）

## 1. 自动更新

### 服务端

- 官网 `website/server.js` 与本地 `server/index.js` 新增 `GET /api/public/app-update`
- 运维只需在 `data/app-update.json` 投放：

```json
{ "version": "1.1.0", "url": "https://jd-hub.top/download", "notes": "修复若干问题", "publishedAt": 1793400000000 }
```

- 没有该文件时返回 `{ version: null }`，客户端静默跳过

### 客户端

- 新增 `src/core/update/updateService.ts`：语义化版本比较、6 秒超时、24 小时缓存、失败静默
- 新增 `UpdateNotice.tsx`：
  - 启动时自动检查，有新版本在顶部显示横幅（版本号 + 更新说明 + 立即下载 + 稍后提醒）
  - 帮助菜单新增「检查更新」，可强制刷新（绕过缓存），无更新时提示「已是最新版本」
- 版本号来自构建期注入的 `APP_VERSION`（package.json 唯一事实源）

### 验证

- 单测：版本比较 5 组、更新检查 3 组
- 实测：投放 `1.1.0` 清单后，启动显示横幅 ✅；关闭后从帮助菜单手动检查再次提示 ✅

## 2. MP4 导出

- 新增依赖 `mp4-muxer`（5.2.2）
- 新增 `src/utils/mp4Encoder.ts`：WebCodecs H.264（avc1 三档 fallback）+ AAC（`mp4a.40.2`）+ mp4-muxer，逐帧编码、关键帧每 2 秒、进度与超时处理与 WebM 一致
- 高级导出 → 视频新增「封装格式」：MP4（H.264 + AAC，适合剪辑）/ WebM（VP9 + Opus，体积更小）
- BGM 会自动循环混音后编码进 MP4；文件名与 `ExportResult.format` 随格式变化

### 验证

- 页面内编码 2 秒、320×180、15fps、带 440Hz BGM 的 MP4，落盘 141 KB
- `ffmpeg -i` 校验：`mov,mp4` 容器，视频 `h264 (Constrained Baseline)`、音频 `aac (LC) 48000 Hz mono`、时长 2.02s ✅
- 导出面板实测：MP4/WebM 选项存在、默认 MP4、说明文案正确
