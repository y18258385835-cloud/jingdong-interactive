# 修复记录 · 第四批（授权码激活体验）

## 1. 修复「激活」入口指错窗口

`App.tsx` 里帮助菜单的「激活授权」原来打开的是 **免费体验弹窗**（一个指向剪映的外链），根本不是输入授权码的地方。现在改为打开 `LicenseActivationModal`。

## 2. 激活弹窗重做

`src/components/LicenseActivationModal.tsx`：

- 顶部显示**当前版本与限制**：免费版 → 「带水印 · 最高 1080p」；专业版 → 「剩余 N 天」
- 明确说明销售方式：*授权码由官方店铺 / 第三方平台销售，一码一机*
- 提供「前往官网了解购买方式」入口（`VITE_PURCHASE_URL` 可覆盖，默认 `https://jd-hub.top/`）
- 说明解锁内容：无水印导出 + 4K 分辨率
- 激活成功后调用 `refresh()` 刷新订阅状态，界面立即从「免费版」切换到「专业版」，不需要重启
- 成功提示从「现在可以导出」修正为「现在可以无水印导出，并解锁 4K 分辨率」（因为免费档已经可以导出）
