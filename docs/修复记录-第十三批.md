# 修复记录 · 第十三批（VFX 结构性拆包）

## 1. 动效元数据索引

`vfxMotions.ts`（250 KB）同时包含「元数据 + 参数定义 + 绘制实现」。首屏只需要元数据（全局搜索、插入默认参数），因此：

- 新增 `tools/build-vfx-index.mjs`：从 `VFX_MOTIONS` 生成 `src/utils/vfxMotionIndex.ts`（40 条，约 39 KB）
- `App.tsx` 的全局搜索与插入逻辑改用 `VFX_MOTION_INDEX`，不再静态引用 `vfxMotions`
- 插入函数签名从 `VfxMotionDef` 放宽为 `VfxMotionMeta`

## 2. 渲染组件懒加载

| 组件 | 改造 |
|---|---|
| `VfxMotionCanvas`（画布渲染） | `React.lazy` + `Suspense fallback={null}`，只有存在 VFX 图层时才加载 |
| `VfxInspector`（右侧属性） | `React.lazy`，只有选中 VFX 图层时才加载 |
| `VfxPresetModal` | 改为条件渲染 + `React.lazy`，打开特效库才加载 |
| `CardLayoutPresetModal` | 同上 |

## 3. 体积变化

| | 上一轮 | 本轮 |
|---|---|---|
| 首屏主 chunk（raw） | 2.32 MB | **2.17 MB** |
| 首屏主 chunk（gzip） | 0.64 MB | **0.59 MB** |
| VFX 实现 | 在主包里 | `VfxMotionCanvas-*.js` 166 KB（按需） |

累计：从最初的 4.68 MB / 1.31 MB gzip 降到 **2.17 MB / 0.59 MB gzip**，首屏 JS 减少约 **54%**（gzip **55%**）。

## 5. 说明

- 开发模式下网络面板会看到 `vfxMotions.ts` 被加载，这是因为默认工程本身含 VFX 图层、需要绘制实现；生产构建中该文件不在首屏 chunk 内。
- 如果工程完全没有 VFX 图层，这 166 KB 不会被下载。
