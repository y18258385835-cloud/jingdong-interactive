# 修复记录 · 第三批（免费档水印导出 / 档位收敛）

## 1. 档位收敛为「免费 + 专业」

- 对外只卖 **专业版（pro）**；`team` 仅保留在数据结构中作为预留（不再出现在任何购买/升级入口，也没有 team 卡密对外销售）。
- 授权服务 `generate()` 默认 `plan = 'pro'`，卡密签发不需要改动。
- 免费档矩阵同步调整（服务端 + 前端一致）：

| 能力 | free | pro |
|---|---|---|
| 工程 JSON 备份 | ✓ | ✓ |
| ZIP / 单文件 HTML / 图片 / 视频导出 | ✓（带水印） | ✓ |
| 无水印 | ✗ | ✓ |
| 4K | ✗ | ✓ |
| 最高导出分辨率 | 1080p | 4k |

## 2. 免费档可以直接导出（带水印）

之前未激活用户点导出会被拦下，现在改为「免费可导出，但带水印」：

- 官网授权服务 `/api/v1/export/authorize` 支持**无令牌**调用：
  - 返回 `plan: "free"`、`watermarkRequired: true`、`maxResolution: "1080p"`
  - 生成 `free-<deviceHash>` 形式的 `licenseRef`，便于追溯，不写入卡密账本
  - 请求 `watermark: false` 会被 403 拒绝（前端按钮只是提示）
- `server/license-service.js` 新增 `authorizeFreeExport()`，本地/自托管服务同样支持。
- `server/index.js` 的导出路由按有无令牌自动分流。
- 客户端 `authorizeExport()` 不再在无令牌时抛错，改为发送免费导出请求。
- 导出面板顶部新增提示：*当前为免费导出：成品右下角会保留「鲸动交互平台」水印，最高 1080p。输入授权码升级专业版即可去水印并解锁 4K。*

## 3. 水印覆盖补全

上一批遗漏了 **ZIP（editor-player 运行时）** 的注入点——ZIP 使用的是预构建播放器骨架，不经过 `generateEmbeddedEditorPlayerHTML`。本批补上：

- `addEditorPlayerRuntime()` 在写入 `index.html` 前注入水印节点
- 至此四种形态全部覆盖：单文件 HTML、ZIP 播放器、独立播放器（standalone）、图片/视频帧
