## 已修复

### P0-5 自定义代码同源执行（安全）

- `src/components/TransparentCustomCodeFrame.tsx` 重写为 `sandbox="allow-scripts"` 的 iframe（不带 `allow-same-origin`）
- `src/utils/customCode.ts` 的沙箱运行时新增 host→iframe 的 `props / measure / focus-text` 消息协议，改动控件属性不再重建 iframe
- 旧实现里的 `new Function(...)` 与同源 `document`/`window` Proxy 全部删除
- 编辑态 iframe 不拦截指针事件，画布仍可选中/拖动自定义代码图层；进入交互预览或双击编辑文字时才接管

**效果**：打开他人分享的工程，代码无法读取 `localStorage` 中的 `aether_auth_token` 与用户自配的模型 Key。

### P0-1 / P0-2 授权签发离开客户端

- `app_launcher.cs`：启动本机服务时注入 `AETHER_LICENSE_MODE=disabled`
- `server/index.js`：disabled 模式下 `license/subscription/export/checkout/admin` 路由一律 404；管理接口默认仅 loopback
- `server/license-service.js`：删除"生产环境空、非生产固定值"的隐式默认，改为必须显式 `AETHER_ALLOW_DEV_LICENSE=1`
- `website/server.js`：删除硬编码 HMAC 密钥与管理员口令哈希，改为环境变量；缺密钥时授权接口 503、管理登录禁用
- `src/core/auth/types.ts`：生产构建默认指向 `https://jd-hub.top`
- `src/core/auth/subscriptionService.ts`：跨域场景改用 `credentials: omit`（否则浏览器 CORS 会直接拦掉授权请求）

### P0-3 桌面端依赖系统 Node

- 启动器优先使用 `runtime\node.exe` → `node\node.exe` → PATH
- 找不到运行时、启动失败、进程立即退出时给出明确弹窗，不再是空 `catch`
- 新增 `scripts/fetch-node-runtime.ps1`（下载 + SHA256 校验 + 解压）与 `npm run runtime:fetch`
- `installer.iss` 增加 `runtime\node.exe` 与 `[UninstallDelete]`

### P0-4 工程备份被授权锁死

- `ExportModal.tsx`：「工程源数据 (JSON)」不再调用 `authorizeExport`，标注「免费 · 离线」
- ZIP / 单文件 HTML 仍需服务端短期导出许可

### 工程治理

- 版本号唯一事实源：`package.json`（1.0.0）；构建期注入 `VITE_APP_VERSION`；新增 `npm run version:check`
- 启动器编译改为 `scripts/build-launcher.ps1`（规避中文输出名在控制台被转码）
- 删除根目录 7 个 shell 重定向误建文件与 13 个 `.env.*.tmp`（含密钥副本）

## 仍需处理（本轮未做）

| 项 | 原因 / 建议 |
|---|---|
| P0-6 在线支付 | 需要确认渠道与商户资质（微信/支付宝/Stripe）。代码侧已预留 `/api/v1/checkout/create`，缺服务端实现 |
| P1-2 功能门禁落地 | `featureGate` 仍是死代码；建议把配额与 4K/去水印判定移到服务端下发的 `features` 上，而不是 UI `disabled` |
| P1-3 ZIP/HTML 水印 | 目前只有图片/视频导出带水印；打包导出缺失，需在 `export.ts` 里补渲染层 |
| P1-6 国际化 | 正则补丁方案需要整体换成资源文件，工作量大且影响所有界面文案 |
| SEC-002 授权签名校验 | 前端仍只校验字段格式。建议服务端改 Ed25519 签名 + 前端内置公钥 `crypto.subtle.verify` |
| SEC-004 令牌存储 | `aether_auth_token` 仍在 `localStorage`；沙箱化后风险显著下降，但仍建议改内存 + 刷新换签 |
| 首屏 4.68 MB 单 chunk | 需要拆包，属于性能专项 |
| `.env.*.tmp` 的根因 | 生产构建/脚本某处仍在写临时 env 文件，建议排查写入方并改为内存传递 |
