# 修复记录 · 第十六批（回归修复 + 付费链路验证）

## 1. 修复控制桥令牌被失败启动覆盖

- 问题：端口被占用导致启动失败时，`installControlBridge` 仍会写入新令牌文件，但实际服务的是旧进程 → MCP 收到 401「控制令牌无效」。
- 修复：
  - `server/control-bridge.js` 支持 `deferDiscovery`，`writeDiscovery()` 只在真正 `listen` 成功后调用
  - MCP `controlRequest` 遇 401 自动重读令牌并重试一次
  - 新增回归用例（2 个）：延迟写入、导出落盘文件名清洗
