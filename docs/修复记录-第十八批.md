# 修复记录 · 第十八批（控制桥变更推送）

## 1. 新增 revision + 长轮询

之前 MCP 只能定时调用 `editor_status` 轮询。现在控制桥维护一个内容版本号：

- 编辑器每次上报快照（每 1.5 秒）时做 SHA1 比对，**只有内容真正变化才递增 `revision`**
- `GET /api/control/state` 返回 `revision`
- 新增 `GET /api/control/events?since=N&timeoutMs=25000`：若 `revision > since` 立即返回，否则挂起等待下一次变更（最长 60 秒）

对应 MCP 工具：

```
editor_status            → 含 revision
editor_wait_for_change   → { since?, timeoutMs? }
```

`since` 不传则以当前 revision 为起点，避免「等待期间已经发生的变更被漏掉」。

## 2. 端到端验收

```
wait_for_change: {"changed":true,"revision":2,"title":"鲸动交互平台 (AETHER) · 官方旗舰全景工程","activeSceneId":"spatial_canvas"}
```

即：先挂起等待，随后通过 MCP 改一次文案，长轮询立刻返回 `changed=true` 与新的 revision。

脚本：`promo/verify-editor-control.mjs`
