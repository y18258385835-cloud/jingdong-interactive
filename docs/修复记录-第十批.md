# 修复记录 · 第十批（MCP 实时控制桥）

## 1. 新增：本地编辑器控制桥

之前 MCP 只能操作导出的 JSON 文件；这一批补上了「直接控制正在运行的编辑器」。

架构：

```
MCP 客户端 ──HTTP──> server/control-bridge.js ──SSE──> 浏览器编辑器
                                   ▲                      │
                                   └──── POST 工程快照 ────┘
```

- 服务端：`server/control-bridge.js`（无第三方依赖，Express + SSE）
- 浏览器端：`src/core/control/editorBridge.ts`（`useEditorControlBridge`）
- 接入点：`App.tsx` 在启动时挂载，周期上报场景/图层快照

## 2. 安全模型

| 措施 | 说明 |
|---|---|
| 仅 loopback | 非 127.0.0.1 / ::1 的请求直接 404 |
| 一次性令牌 | 启动时随机生成，写入 `data/control-token.json`（本机同用户可读） |
| Origin 白名单 | 只接受 localhost / 127.0.0.1 页面，阻断恶意网页调用 |
| 常量时间比较 | 令牌校验使用 `timingSafeEqual` |
| 能力最小化 | 只暴露「读状态 / 改文案 / 切场景」，没有文件系统能力 |

## 3. MCP 新增工具

| 工具 | 作用 |
|---|---|
| `editor_status` | 读取当前工程、场景、图层数量 |
| `editor_select_scene` | 让编辑器切换场景 |
| `editor_set_layer_text` | 实时修改文本图层（无需导出/导入） |

配合原有的 7 个文件级工具，MCP 现在共有 **10 个工具**。
