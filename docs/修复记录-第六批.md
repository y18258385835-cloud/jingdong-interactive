# 修复记录 · 第六批（拆包第二轮 + 体积可视化）

## 1. 导出模块移出首屏

`ExportModal` 原来是静态导入（`react.lazy` 只包了 `AdvancedExportModal`），导致整个 `utils/export.ts`（299 KB 源码）和 JSZip 相关代码进入首屏主包。

- 改为 `React.lazy`，并且只在 `isExportModalOpen` 为真时挂载，避免首次渲染就触发加载
- 首屏主包 2.87 MB → **2.56 MB**（gzip 0.76 → **0.67 MB**）
- 新增独立 chunk `ExportModal-*.js`（0.29 MB），点击导出时才加载

## 2. 体积分析工具

- 新增 `rollup-plugin-visualizer`（devDependency），`ANALYZE=1` 时生成 `promo/bundle-stats.json`
- 新增 `tools/report-bundle.mjs`：解析 stats，按模块输出主 chunk 体积 Top 25
- 新增 `npm run analyze`（构建 + 报告）、`npm run bundle:report`（只出报告）
