# 修复记录 · UI 改版（组件库预览）

## 问题

组件库（Galaxy UI 组件库）打开后：

- 所有卡片大小、明暗几乎一样，没有视觉重心
- 卡片里的预览只有 96px 高、缩放上限 0.7，组件细节看不清
- 右侧预览区默认是空状态，进一步稀释了焦点
- 弹窗固定 900×600，内容被裁切，只能看到一行半

## 改动

### 1. 精选区（新增视觉焦点）

- 组件库顶部新增「精选组件」分组，4 个代表组件（玻璃卡片 / 指标卡片 / 霓虹按钮 / 数据可视化标题）
- 精选卡片预览高度 144px、缩放上限 0.62，明显大于普通卡片
- 普通网格里不再重复展示这些组件

### 2. 卡片重做

- 预览区 96px → 112px，深色舞台 + 顶部径向高光，组件轮廓更清楚
- 悬停：整卡上浮 2px、边框转青色、出现「点击编辑 →」
- 选中：青色描边 + 左上「已选」胶囊
- 标题单行截断（`title` 悬浮显示全名），分类改为小胶囊标签

### 3. 右侧预览区

- 打开组件库自动预览「精选第一个组件」，不再显示空状态
- 预览舞台 190px → 220px，加径向高光和「实时预览」角标
- 未手动选择时也保持一个稳定焦点，插入按钮语义不变

### 4. 弹窗尺寸

- `900×600` → `1040×78vh`（最大 860px、最小 560px），并支持小屏自适应

### 5. 顺手修复

- `PyramidDistributionChart` 的 `<defs>` 内 Fragment 缺 `key` 导致 React 警告（长期存在的噪音），已修复
