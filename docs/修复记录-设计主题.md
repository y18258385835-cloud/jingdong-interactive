# 设计令牌 / 工程主题修复记录

> 目标：把颜色、字体、字号、圆角、阴影变成工程级“设计令牌”，能一键提取、保存、应用，后续新建图层也自动沿用。

## 现在能做什么

顶部工具栏右侧点「主题」：

- 编辑 7 个颜色令牌：画布背景、卡片底色、主色、辅助色、主文字、次文字、边框；
- 编辑字体、正文字号、标题字号、圆角、阴影；
- 「从工程提取」：自动统计当前工程最常用的背景色、文字色、字体、字号、圆角，生成一套主题；
- 「保存主题」：写入工程，之后新建文字/卡片自动使用；
- 「应用到工程」：按勾选项批量更新现有图层：
  - 背景：只改没有背景图的场景；
  - 文字颜色：改普通文字和卡片内文字，文字特效预设不强制改色；
  - 字体/字号：普通文字按原字号是否 ≥24px 自动套正文/标题字号；
  - 圆角：只改原本有圆角的图形；
  - 阴影：只改原本有阴影的图形；
- 应用后可用 `Ctrl+Z` 撤销。

## 实测

```text
提取主题 → 命名为「测试主题」
背景色改为 #123456
主文字改为 #00ff00
圆角改为 28
保存主题 ✅
应用到工程 ✅

结果：
主题数据 = { name: 测试主题, background: #123456, text: #00ff00, radius: 28 }
无背景图场景背景 = #123456 ✅
文字颜色 = #00ff00 ✅
图形圆角 = 28 ✅
```

截图：`promo/out/galaxy/theme-panel.png`

验证脚本：`promo/probe-theme.mjs`

## 当前 v1 限制

- 批量应用是“按通用规则替换”，不是每个组件单独绑定令牌；
- 图表、自定义代码、官方 UI 组件的内部颜色暂不批量替换；
- 有背景图的场景保留背景图，不会为了换主题删掉原图；
- 主色/辅助色目前主要影响新图层和后续组件，不会强行改所有旧图层的强调色；
- 主题随工程保存和导出，但不会跨设备同步。
