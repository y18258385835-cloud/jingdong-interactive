# 修复记录 · 第二批（授权门禁与水印）

本轮聚焦「付费档位真正生效」与「导出内容可追溯」，不涉及支付（授权码由第三方平台销售）。

## 1. 服务端成为唯一门禁

`website/server.js` 新增档位矩阵：

| 能力 | free | pro | team |
|---|---|---|---|
| 工程导出 / 无水印 / 4K / 视频 / HTML / ZIP | ✗ | ✓ | ✓ |
| 批量导出 / API 访问 | ✗ | ✗ | ✓ |
| 最高导出分辨率 | 720p | 4k | 4k |
| 单次视频时长 | 5 分钟 | 60 分钟 | 120 分钟 |

- `/api/v1/subscription/verify` 与 `/license/status` 现在返回 `features` / `quotas`，客户端不再靠猜。
- `/api/v1/export/authorize` 接收 `{ format, resolution, watermark }` 并在服务端校验：
  - 分辨率超过档位 → 403「当前授权最高支持 X 导出」
  - `watermark === false` 但档位不支持无水印 → 403
  - 同时补上了**授权过期校验**（此前只校验 `revoked`，过期卡仍可导出）

## 2. 客户端门禁从死代码变成真调用

- `subscriptionService` 新增 `hasFeature()` / `maxExportResolution()`。
- `AdvancedExportModal`（图片/视频）：
  - 4K 按钮按 `quotas.maxExportResolution` 放行，不再是 `isPaid` 硬编码
  - 水印开关按 `features.export_no_watermark` 放行，档位不足时强制开启并显示「当前授权强制」
  - 授权变更后自动把水印锁回、把越界分辨率降回 1080p
- `ExportModal`（ZIP / 单文件 HTML）同样按 `export_no_watermark` 决定是否强制水印，并把结果传给导出器。

## 3. 水印覆盖所有交付形态

- 新增 `src/utils/exportWatermark.ts`：统一的右下角胶囊水印（转义文案、透明度 0.2–1）。
- 注入点：
  - `generateStandaloneHTML`（`runtime: 'standalone'`）
  - `generateEmbeddedEditorPlayerHTML`（ZIP 的 editor-player 与单文件 HTML 共用）
  - 视频导出逐帧绘制（此前视频完全没有水印）
  - 图片导出复用同一套绘制逻辑，并修正文案「鲸动互动平台」→「鲸动交互平台」
- 空导出（无授权）不会出现水印节点，避免误伤已付费用户。
