# 自定义代码「智能参数」修复记录

> 目标：AI 生成的参数必须和组件真实内容一一对应。统计表就生成表头、数值、配色、字号、圆角，而不是速度/缩放/循环这类拖了没反应的通用参数。

## 现象

自定义代码组件（例如统计表）点击「AI 生成」后，参数面板出现的是：

- 动效运行速度
- 组件缩放比例
- 动画循环开关
- 主题色 / 辉光

拖动这些参数时，统计表本身没有任何变化。用户看到的就是“AI 很傻”。

## 根因

不是模型不够聪明，而是参数没有落到真实 DOM/CSS 上：

1. **AI 在凭空发明 key**
   `/api/llm/extract-controls` 只把截断后的代码丢给模型，让模型自由返回 `key`。运行时只认识自己生成的 `text-N` 和 CSS 变量，模型发明的 `tableHeaderColor` 之类的 key 没有任何写入路径。

2. **文本参数没有写回通道**
   旧运行时把所有 props 统一写成 CSS 变量 `--key`。文本/数值不是 CSS 变量，所以即使 key 猜对了，也改不了表头文字。

3. **iframe 模板里的 `\d` 被吞掉**
   文本写回正则写在运行时模板字符串里：

   ```ts
   if (/^text-\d+$/.test(key)) { ... }
   ```

   模板字符串会把 `\d` 解析成 `d`，最终 iframe 里执行的是 `/^text-d+$/`，永远匹配不到 `text-0`。

4. **字号/圆角变量缺少单位**
   控件下发的是纯数字 `12`，CSS 却是 `font-size: var(--ctl-font-1, 12px)`。`var()` 解析后变成 `font-size: 12`，是非法值，浏览器回退到 16px；圆角同理回退到 0。

5. **二次识别会丢参数**
   第一次识别后 CSS 已经被替换成 `var(...)`，第二次再跑识别时找不到颜色/字号/圆角字面量，参数面板会被“洗掉”。

6. **内联改字会把参数打回原值**
   运行时在内联编辑结束时把 `data-aether-text-key` 删掉了，并且只回传 HTML、不把新文字同步到控制值。iframe 重载后旧 props 又把文字覆盖回去。

## 修复方案

### 1. 本地结构识别（真实落点）

新增 `src/utils/customCodeSmartControls.ts`：

- `collectTextHits`（`:43`）：扫描 HTML 文本叶子，按 `th`、表头 class、数值、`td` 等打分，选出最多 10 个真正值得调的文字。
- `instrumentText`（`:92`）：给文本叶子写入稳定的 `data-aether-text-key="text-N"`。
  - 已存在的 key 一律保留。
  - 新 key 会避开所有已存在的 key，防止内联编辑后撞车。
- 颜色：扫描真实颜色字面量，替换成 `var(--ctl-color-N, 原值)`，最多 4 个。
- 字号：替换成 `calc(var(--ctl-font-N, 原值) * 1px)`（`:239`），支持 px/rem/em/%，解决单位丢失。
- 圆角：替换成 `calc(var(--ctl-radius-1, 原值) * 1px)`（`:268`）。
- `mergeExistingSmartControls`（`:169`）：二次识别时保留已经落地的配色/字号/圆角参数，并保留用户/AI 已确认的标签。
- 所有 key 都有明确落点，不存在“面板里有、拖了没反应”。

### 2. AI 只负责命名，不负责发明

`src/components/CustomCodeDynamicControls.tsx`：

- `getSmartCustomCodePlan`（`:121`）：先跑本地识别；作者写了 `@control` / `@schema` 时优先使用作者声明。
- `handleAiExtract`（`:266`）：
  1. 本地识别生成候选参数；
  2. 请求携带 `candidates`（`:286`）；
  3. AI 只返回 `{ key, label, group }`；
  4. `mergeAiControlNaming`（`:318`）按 key 合并，未知 key 直接丢弃；
  5. AI 失败/没配置 Key/返回空时，回退本地识别，**不再退化成速度/缩放**。
- 「一键装配常用调节滑块」（`:177`）也改成优先本地识别，只有完全识别不到落点时才用通用预设。

服务端 `server/index.js`：

- `candidateList`（`:791`）只接受候选里的 key。
- `candidates` 分支使用独立 prompt（`:822`）：明确要求“只改名/分组，不得发明、删除、合并 key”。
- 返回前二次过滤（`:917`）：AI 返回的未知 key 一律丢弃，只返回 `{ key, label, group }`。

### 3. 运行时写回

`src/utils/customCode.ts`：

- `assignTextKeys`（`:316`）：保留已有 key，其余按可用序号补 `text-N`，不再出现重复 key。
- 文本 props 写回（`:431`）：`text-N` 直接写到对应文本叶子，不重建 iframe。
  - 用 `key.startsWith('text-')` + 纯数字判断，避开模板字符串转义问题。
- CSS 变量同时写到 root / `document.documentElement` / `body`（`:442`），作者写在 `body`、`:root` 上的样式也能生效。
- 内联编辑结束时把 HTML、`textKey`、新文字一次性回传（`:371`），不再分两次更新互相覆盖。

`src/components/CanvasViewport.tsx` / `src/components/TransparentCustomCodeFrame.tsx`：

- 转发 `textKey` / `value`（`CanvasViewport.tsx:6242`、`:6267`，`TransparentCustomCodeFrame.tsx:92`）。
- `handleCustomCodeTextChange`（`CanvasViewport.tsx:2394`）一次提交：
  - 更新 HTML；
  - 更新 `textOverrides`；
  - 如果该 key 是智能参数，同时更新 `customCodeProps` / `controlValues`。
- 内联改字后参数面板显示新值，iframe 重载也不会被旧值覆盖。

### 4. 开发环境联调

`vite.config.ts:103` 增加 `^/api/llm/extract-controls` 代理，开发服与安装包的后端行为保持一致。

## 复现样例

统计表 HTML：

```html
<table class="stats-table">
  <thead>
    <tr><th>姓名</th><th>部门</th><th>绩效</th></tr>
  </thead>
  <tbody>
    <tr><td>陈晓</td><td>产品部</td><td class="value">98.6%</td></tr>
    <tr><td>李明</td><td>研发部</td><td class="value">94.2%</td></tr>
  </tbody>
</table>
```

CSS 关键部分：

```css
.stats-table {
  background: #0f172a;
  color: #e2e8f0;
  font-size: 12px;
  border-radius: 12px;
}
.stats-table th { color: #94a3b8; font-size: 11px; }
.stats-table .value { color: #38bdf8; font-size: 14px; }
```

验证脚本：`promo/probe-smart-controls.mjs`

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH='D:\AI_Tools\playwright_browsers'
node promo/probe-smart-controls.mjs http://127.0.0.1:3000
```

## 验证结果

### 识别结果

统计表样例生成 **17 项**参数：

| 类型 | 数量 | 示例 |
|---|---|---|
| 文本/数值 | 9 | 表头 · 姓名、表头 · 部门、数值 · 98.6% |
| 颜色 | 4 | 背景颜色 1、文字颜色 2 |
| 字号 | 3 | 字体大小 1 / 2 / 3 |
| 圆角 | 1 | 圆角 |

### AI 命名

假 LLM 返回 7 个合法 key + 1 个越界 key `speed`：

- 前端最终显示：员工姓名、所属部门、绩效指标、绩效数值、表格底色、表格字号、卡片圆角；
- `speed` / `动画速度` 被服务端丢弃；
- 其余未命名参数保留本地标签。

### 调节效果（画布真实 iframe）

| 操作 | 期望 | 实测 |
|---|---|---|
| 表头文字 姓名 → 王五 | iframe 表头变化 | `AFTER_TEXT "王五"` |
| 背景色 `#0f172a` → `#7c2d12` | 表格背景变化 | `rgb(124, 45, 18)` |
| 字号 12 → 20 | 表格字号变化 | `20px` |
| 圆角 12 → 24 | 表格圆角变化 | `24px` |

### 内联改字

双击画布进入文字编辑，把「王五」改成「赵六」后：

```json
{
  "prop": "赵六",
  "override": "赵六",
  "htmlKeepsKey": true
}
```

iframe 重载后仍显示「赵六」，参数面板同步为「赵六」。
