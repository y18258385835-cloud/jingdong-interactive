# 修复记录 · 第十四批（GalaxyComponents 拆包）

## 1. 抽出轻量元数据模块

`GalaxyComponents.tsx` 里混着「类型 + 基础尺寸 + 渲染实现」。先把元数据抽到 `src/components/ui/galaxyComponentMeta.ts`：

- `GalaxyComponentType`
- `GALAXY_COMPONENT_BASE_SIZE`
- `CONTINUOUS_INTERACTION_COMPONENT_TYPES` / `isContinuousInteractionComponent`

`GalaxyComponents` 改为从该模块导入并继续对外导出，调用方无需改动。

随后把这些只用到元数据的模块切到新入口：

- `App.tsx`（插入组件时的基础尺寸）
- `CanvasViewport.tsx`（尺寸与连续交互判定）
- `InspectorPanel.tsx`（连续交互判定）
- `plugins/pluginStudio.ts`

## 2. 渲染实现改为按需加载

| 位置 | 变化 |
|---|---|
| `CanvasViewport` 的 `ScaledUIComponent` | 改为 `React.lazy` + 包装组件（`Suspense fallback=null`） |
| `UILibraryModal`（组件库） | 条件渲染 + `React.lazy` |
| `OfficialComponentsModal`（官方组件） | 同上 |
| `PluginCenterModal`（插件中心） | 同上 |
| `LeftSidebar` 的 `PluginCenterPanel` | 切到「插件」标签时才加载 |
