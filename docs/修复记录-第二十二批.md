1. **忽略空白**：`切换到场 景设置` 能命中 `切换到场景设置`
2. **统一括号**：`未分配分组 (独立图层)` 与 `未分配分组（独立图层）` 视为同一条
3. **通用标签规则**：`标签（值）` / `标签: 值` 只翻译标签，值原样保留
4. **不放行半成品**：正则/组合替换后若仍含中文，整段保留原文
