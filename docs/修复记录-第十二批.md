# 修复记录 · 第十二批（控制桥导出 + 断线重连）

## 1. 新增 `editor_export`

MCP 现在可以让正在运行的编辑器直接导出：

| 参数 | 说明 |
|---|---|
| `format` | `zip`（默认）/ `single-html` / `json` |

行为：

- 走完整的导出门禁：需要授权；免费档自动带水印并消耗免费次数（JSON 不占次数）
- 导出完成后由浏览器触发下载，MCP 收到回执（含文件名）
- ZIP 打包可能超过 5 秒，命令默认等待 5 秒、导出类命令传 `timeoutMs: 120000`

## 2. 控制桥断线重连

服务重启后令牌会变化，之前编辑器会一直用旧令牌重连。现在：

- `EventSource.onerror` 触发后关闭连接、清掉状态上报定时器
- 10 秒后重新 `handshake` 拿新令牌再连接
- 组件卸载时清理重连定时器

## 5. 已知限制

- 浏览器对「非用户手势触发的下载」有策略限制：连续多次 `editor_export` 可能弹出「允许下载多个文件」提示
- 导出仍在用户本机完成，MCP 拿到的是文件名而不是文件本体（文件在浏览器下载目录）
- 如果希望 MCP 直接拿到文件，需要额外设计「导出到指定目录」的受限写入能力
