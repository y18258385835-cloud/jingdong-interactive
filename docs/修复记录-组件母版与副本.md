# 组件「母版-副本」修复记录

> 目标：像墨刀/PPT 母版一样，改一次母版，所有副本一起变；副本还能单独改文字、颜色、显隐，并支持默认/悬停等状态。

## 原来的问题

1. **旧“组件库”只是复制粘贴**
   `ComponentPreset` 只存一份 `elements` 数组。插入时整段 JSON 深拷贝，改一个组件，其他副本完全不变。

2. **入口藏得深**
   用户自己存的组件在右侧「数据」检查器里，左侧「组件」面板只有官方组件，找起来像捉迷藏。

3. **组件副本没有名字**
   图层列表和时间线里只显示“合并图层组（3）”，多个副本分不清谁是谁。

4. **没有状态/变体**
   同一个按钮的默认/悬停/禁用只能靠复制多个图层，改起来容易漏。

## 现在的数据模型

### 母版

`ComponentPreset` 扩展为：

- `elements`：默认状态图层（兼容旧组件）；
- `variants`：状态列表，例如「默认」「悬停」「禁用」；
- `width` / `height`：母版画布尺寸（百分比）；
- `version` / `updatedAt`：版本号，更新母版时递增。

### 副本

组件副本仍然是一个「分组图层」，额外带：

```ts
componentInstance: {
  masterId: string;
  variantId?: string;
  overrides?: Record<string, Partial<SceneElement>>;
}
```

每个子图层带 `componentSourceId`，用来对应母版里的源图层。

- 母版更新时，按 `componentSourceId` 把新外观同步到所有副本；
- 副本自己的文字/颜色/显隐覆盖存在 `overrides` 里，不会被母版覆盖；
- 副本位置、大小由分组自身决定，移动/缩放副本不会影响母版。

## 使用方式

### 1. 存为母版

1. 在画布或图层列表选中 1 个或多个文字/图形/图表/UI 组件；
2. 打开左侧「组件」面板；
3. 在「我的组件（母版）」里输入名称，点「存为母版」。

选中的图层会被替换成一个组件副本，母版存进当前工程。

### 2. 插入副本

在母版卡片上点「插入」，会生成「组件名 · 副本 N」，可继续移动、缩放、旋转。

### 3. 改母版，所有副本同步

1. 选中任意副本；
2. 在左侧「当前副本」或右侧检查器里修改文字/颜色/显隐；
3. 点「更新母版」；
4. 工程内所有副本同步新外观，其他副本自己的覆盖项会保留。

### 4. 单独改副本

「当前副本」下面的文字/颜色/显隐只影响当前副本；点「重置」可恢复母版外观。

### 5. 状态/变体

1. 选中副本，改好外观；
2. 输入状态名（如「悬停」），点「存为状态」；
3. 在状态下拉框里切换「默认 / 悬停」，副本会切换对应外观。

### 6. 分离 / 删除母版

- 「分离副本」：断开母版链接，变成普通图层组，可自由修改；
- 删除母版：已有副本会保留并自动分离，不会丢内容。

## 兼容旧工程

- 旧组件预设没有 `width/height/variants`，读取时自动计算包围盒并转成「默认」状态；
- 旧组件库的「一键插入」已改为插入**关联副本**，不再复制一堆散图层；
- 旧工程不需要迁移，打开即可用。

## 实测结果

用首页三个标题文字做完整链路：

| 步骤 | 结果 |
|---|---|
| 存为母版 | 母版 v1，默认状态，副本 1（3 个子图层） |
| 插入副本 | 出现「测试卡片 · 副本 2」 |
| 副本 1 改字「覆盖一」→ 更新母版 | 母版 v2，两个副本都变「覆盖一」 |
| 副本 2 改字「副本二」；副本 1 改「母版二次」→ 更新母版 | 母版 v3；副本 1「母版二次」，副本 2 保留「副本二」 |
| 副本 2 存为「悬停」状态 | 母版 v4，2 个状态；副本 2 切到悬停 |
| 切回默认 | 副本 2 显示「母版二次」 |
| 再切悬停 | 副本 2 显示「副本二」 |
| 分离副本 2 | 只剩副本 1 关联母版 |
| 删除母版 | 副本自动分离，工程组件库清空 |

## 当前 v1 限制

- 可存为母版的图层类型：文字、图形、图片、视频、图表、UI 组件、Saber/VFX；
- 自定义代码、3D、全景暂不进入母版（它们的渲染依赖独立运行时）；
- 暂不支持“母版里再嵌套母版”；
- 副本覆盖目前提供文字、颜色、显隐；图表数据等复杂属性后续再补。
