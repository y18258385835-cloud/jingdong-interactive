# 分享交付修复记录

> 目标：把工程发布成「局域网链接 + 二维码」，客户用同网段手机/电脑直接打开；没有可用的分享服务时，退回下载已经授权的单文件 HTML。

## 怎么用

1. 顶部工具栏点「分享」。
2. 点「生成分享链接与二维码」。
3. 生成后可以：
   - 手机扫二维码直接打开；
   - 复制链接发给同网段的电脑；
   - 点「打开」在本机预览；
   - 下载单文件 HTML 作为兜底交付物。

分享弹窗截图：`promo/out/galaxy/share-modal.png`  
手机打开效果：`promo/out/galaxy/share-mobile.png`

## 链路

```text
点击分享
  → subscriptionService.authorizeExport('single-html', { watermark })
  → exportSingleFileHTML(project, { exportProof, watermark })
  → POST /api/share/publish  （本机/局域网后端，内存快照）
  → 返回 http://<局域网 IP>:8080/share/<24位token>
  → qrcode 生成二维码
```

- `src/components/ShareModal.tsx:141`：复用 `exportSingleFileHTML`，水印、导出证明、评论剥离都由现有导出链路处理。

## 授权与水印

- 免费档：`hasFeature('export_no_watermark')` 为 false，弹窗固定开启水印，并明确提示「占用一次免费额度」。
- 服务端 `authorizeExport` 本身也会按设备扣免费额度；免费额度用完会直接返回 403，分享不会生成。
- 分享生成的 HTML 里包含现有导出的水印节点：`data-aether-watermark="1"`。
- 分享和 ZIP/单文件导出使用同一个授权入口，没有单独放宽。

## 重要限制

- 分享快照存在后端内存里：默认 **2 小时**后失效，后端重启立即失效。
- 单个快照上限 **20 MB**；整个内存池上限 **200 MB / 100 条**，超出会淘汰最旧快照。
- 链接是 `http://<局域网 IP>:8080`，手机和电脑必须在同一 Wi-Fi/局域网；Windows 防火墙需要放行 8080。
- 只适合局域网评审，不是公网发布；不要把链接当成长期交付地址。
- 如果检测不到局域网 IP，弹窗会提示「当前链接只能在这台电脑打开」。
- 没有可用的分享服务时，会退回下载已经授权的单文件 HTML；但**不会**在未授权的情况下生成导出物。
