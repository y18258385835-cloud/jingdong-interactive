一、系统配置与运行环境要求

🖥️ 最低运行环境配置

操作系统：Windows 10 64位 (1909 及以上) 或 Windows 11
处理器：Intel Core i3 / AMD Ryzen 3 或更高
内存：4 GB RAM
图形卡：支持 DirectX 11 / OpenGL 4.3 显卡
网络：首次激活需联网鉴权，激活后支持脱机免网长期运行

🚀 推荐专业展览环境配置

操作系统：Windows 10/11 64位 专业版/企业版
处理器：Intel Core i7 / AMD Ryzen 7 或更高
内存：16 GB RAM 或以上
图形卡：NVIDIA GeForce RTX 3060 或独立专业显卡
外设接口：千兆网口 (连接激光雷达点云/中控网络)

二、常见问题与操作指引 (FAQ)

Q1: 从 Microsoft Store 安装后，如何获取授权与激活？

首次安装启动后，软件提供基础演示工程体验。若需导出单文件 HTML、离线 Player 运行包或启用多通道雷达中控，请进入软件顶部菜单【授权激活】，输入您购买或商务顾问发放的激活卡密（格式如 JDINT-XXXX-XXXX-XXXX），点击激活即可自动绑定本机完成永久或期限授权。

Q2: 展厅环境无外网连接，软件是否可以离线运行？

完全可以！鲸动交互平台专为商业展陈设计。软件在首次联网完成激活码认证后，数字签名许可证将永久驻留于本地系统安全存储区，日常展厅断网或脱机工控机环境均可正常满血启动运行。

Q3: 软件支持哪些雷达和互动传感器硬件？

原生集成思岚科技 (Slamtec)、北醒 (Benewake)、星秒 (Siminics)、EAI 等主流 2D/3D 激光雷达点云协议，并支持通过 UDP、OSC、WebSocket 及 Art-Net DMX512 进行多协议声光电中控设备联动。

Q4: 如果需要更换电脑工控机设备，如何迁移授权？

请将您的原始订单凭证、购买卡密以及新旧工控机的硬件信息发送至开发者支持邮箱 contact@jd-hub.top，技术团队将在 24 小时内为您完成云端解绑与换机重新发放。
