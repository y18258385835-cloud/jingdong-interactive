# 发布前回归清单

每次发布必须先执行 `npm run test:release`。该命令会依次运行完整自动化测试、TypeScript 类型检查、生产构建和生产依赖安全审计；任一步失败均不得发布。

`npm run test:regression` 保留给日常开发时的快速回归，不可替代发布门禁。自动检查通过后，在目标部署环境的浏览器完成以下链路：

1. 导入 `.aether`/JSON/图片/视频/3D/全景资源。
2. 编辑图层和交互，保存后刷新页面确认数据恢复。
3. 复制图层/场景，执行撤销和重做。
4. 编辑器预览中验证点击、悬停、弹窗、场景跳转、链接和变量修改。
5. 分别导出 HTML、ZIP、图片/视频，检查进度、取消和失败重试。
6. 将导出的工程再次导入，运行资源缺失扫描并确认修复提示。

自动化测试覆盖工程数据归一化、授权、导出、Saber、模板、工程健康检查、任务取消与超时。真实浏览器权限、硬件体感和第三方 AI 服务仍需在发布环境执行上述清单。
